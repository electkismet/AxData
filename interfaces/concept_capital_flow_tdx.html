题材资金走势

concept_capital_flow_tdx

按题材或行业 ID 查询主力资金走势。

接口信息

接口名
concept_capital_flow_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / 短线数据
资产类型
stock
请求模式
source_request
采集支持
否

按题材或行业 ID 查询主力资金走势。

参数

参数类型必填说明默认值
concept_codestring是题材或行业 ID；可先从个股题材接口返回的 topic_id 中选择，部分 ID 可能没有资金走势。
start_datestring否起始日期，可选；按 date 过滤。
end_datestring否结束日期，可选；按 date 过滤。
countinteger否返回条数，默认 20，最大 500。20
参数说明

按题材或行业 ID 返回资金走势；并非相关板块的 board_code 都可用，部分 ID 可能没有资金走势。

参数示例

client.call("concept_capital_flow_tdx", concept_code="2817", count=5)

返回字段

字段类型说明
board_namestring题材或行业名。
datedate日期。
main_amountnumber主力资金。
main_buy_amountnumber主买资金。
avg_main_amountnumber平均主力资金。
avg_main_buy_amountnumber平均主买资金。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "concept_capital_flow_tdx",
    concept_code='2817',
    count=20,
)
