新浪期货成交持仓排名

futures_hold_pos_sina

临时获取新浪财经新浪期货成交持仓排名数据，默认不入库。

接口信息

接口名
futures_hold_pos_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期货行情
资产类型
future
请求模式
source_request
采集支持
否

临时请求新浪期货单合约成交/持仓排名，默认不入库。

参数

参数类型必填说明默认值
symbolstring否指标名称，可选：成交量、多单持仓、空单持仓；默认 多单持仓。"多单持仓"
contractstring否期货合约代码，例如 OI2501；默认 OI2501。"OI2501"
datestring否查询日期，YYYYMMDD 或 YYYY-MM-DD；默认 20241016。"20241016"
limitinteger否最多返回行数，默认 20，最大 100。20

返回字段

字段类型说明
trade_datedate查询交易日期，格式 YYYYMMDD。
contractstring期货合约代码，例如 OI2501。
metricstring持仓成交指标：成交量、多单持仓或空单持仓。
rankinteger源端排名，从 1 开始。
member_namestring期货公司或会员简称。
valuenumber对应指标数值，成交量或持仓量，单位：手。
changenumber比上一交易日增减，单位：手。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "futures_hold_pos_sina",
    contract='OI2501',
    date='20241016',
    limit=1,
    symbol='多单持仓',
)
