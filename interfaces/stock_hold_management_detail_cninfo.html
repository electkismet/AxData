高管持股变动明细

stock_hold_management_detail_cninfo

临时获取巨潮高管持股变动明细数据，默认不入库。

接口信息

接口名
stock_hold_management_detail_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 股本股东
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮高管持股变动明细，按变动类型和公告区间返回，默认不入库。

参数

参数类型必填说明默认值
change_typestring否变动类型：增持、减持；默认 增持。"增持"
start_datestring否公告开始日期，YYYYMMDD 或 YYYY-MM-DD；默认 20240101。"20240101"
end_datestring否公告结束日期，YYYYMMDD 或 YYYY-MM-DD；默认 20241231。"20241231"
limitinteger否最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
change_typestring变动类型：增持、减持。
end_datedate截止日期，格式 YYYYMMDD。
announcement_datedate公告日期，格式 YYYYMMDD。
executive_namestring高管姓名。
director_supervisor_senior_namestring董监高姓名。
director_supervisor_senior_positionstring董监高职务。
changer_relationstring变动人与董监高关系。
beginning_holding_sharesnumber期初持股数量，单位/口径沿用巨潮源端。
ending_holding_sharesnumber期末持股数量，单位/口径沿用巨潮源端。
change_sharesnumber变动数量，单位/口径沿用巨潮源端。
change_rationumber变动比例，源端百分比数值口径。
average_pricenumber成交均价，单位：元。
ending_market_valuenumber期末市值，金额单位/口径沿用巨潮源端。
change_reasonstring持股变动原因。
data_sourcestring数据来源。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()

    "stock_hold_management_detail_cninfo",
    change_type='增持',

    limit=1,
    start_date='20240101',
)
