ETF列表

etf_codes_tdx

获取通达信代码表里的 ETF 列表。

接口信息

接口名
etf_codes_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / ETF数据 / 基础数据
资产类型
etf
请求模式
source_request
采集支持
否

这个接口和最新股票列表同源，都是从代码总表里筛选。股票列表只筛股票，ETF 列表只筛 ETF。

参数

参数类型必填说明默认值
namestring否ETF 简称过滤，例如 50ETF、沪深300ETF。
codestring否ETF 代码过滤：支持 510050.SH、159915.SZ、sh510050。
exchangestring否交易所过滤：all 全部、SSE 上交所、SZSE 深交所；默认 all。"all"
参数示例

# 全部 ETF 列表 client.call("etf_codes_tdx") # 指定几个 ETF client.call("etf_codes_tdx", code=["510050.SH", "510300.SH", "159915.SZ"])

返回字段

字段类型说明
instrument_idstringAxData 统一 ETF 代码，例如 510050.SH。
symbolstring交易所原始六位 ETF 代码。
tdx_codestringTDX 带市场前缀代码，例如 sh510050。
exchangestringAxData 交易所代码：SSE 或 SZSE。
namestringETF 简称。
previous_closenumber代码表携带的昨收价。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "etf_codes_tdx",
    code=['510050.SH', '159915.SZ'],
)

HTTP API

POST /v1/request/etf_codes_tdx
Content-Type: application/json

{
  "params": {
    "code": [
      "510050.SH",
      "159915.SZ"
    ]
  }
}
