接口文档 / 新浪财经

指数成份股

index_stock_cons_sina

临时获取新浪财经指数成份股数据，默认不入库。

接口信息

接口名
index_stock_cons_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 指数行情
资产类型
index
请求模式
source_request
采集支持
否

临时请求新浪指数成份股行情单页，默认不入库。

参数

参数类型必填说明默认值
symbolstring否六位指数代码，默认 000300。"000300"
pageinteger否页码，默认 1。1
limitinteger否每页条数/最多返回行数，默认 80，最大 3000。80

返回字段

字段类型说明
index_codestring指数代码。
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
sina_symbolstring新浪带市场前缀代码，例如 sh600000。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
latest_pricenumber最新价，单位：元。
changenumber涨跌额，单位：元。
change_pctnumber涨跌幅，源端百分比数值口径。
bidnumber买入价，单位：元。
asknumber卖出价，单位：元。
prev_closenumber昨收，单位：元。
opennumber今开，单位：元。
highnumber最高价，单位：元。
lownumber最低价，单位：元。
volumenumber成交量，单位/口径沿用新浪源端。
amountnumber成交额，金额单位/口径沿用新浪源端。
tick_timestring源端行情时间。
penumber市盈率。
pbnumber市净率。
market_capnumber总市值，金额单位/口径沿用新浪源端。
float_market_capnumber流通市值，金额单位/口径沿用新浪源端。
turnover_rationumber换手率，源端百分比数值口径。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "index_stock_cons_sina",
    limit=1,
    page=1,
    symbol='000300',
)
