接口文档 / 东方财富

盘口异动列表

eastmoney_stock_changes

临时获取东方财富盘口异动列表数据，默认不入库。

接口信息

接口名
eastmoney_stock_changes
Provider
axdata.source.eastmoney
数据源
东方财富 / eastmoney
目录
东方财富 / 短线数据
资产类型
stock
请求模式
source_request
采集支持
否

请求东方财富盘口异动列表，默认不入库。

参数

参数类型必填说明默认值
change_typestring否异动类型编码，默认 8201（火箭发射）。"8201"
filter_stboolean否是否过滤 ST 和三板股票，默认 true。true

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
market_codestring东方财富市场代码。
change_timestring异动时间，HHMMSS。
change_pctnumber涨跌幅，百分比数值。
change_typestring异动类型编码。
change_type_namestring异动类型名称。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "eastmoney_stock_changes",
    change_type='8201',
)
