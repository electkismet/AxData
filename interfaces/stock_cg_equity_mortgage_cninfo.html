接口文档 / 巨潮

股权质押

stock_cg_equity_mortgage_cninfo

临时获取巨潮股权质押数据，默认不入库。

接口信息

接口名
stock_cg_equity_mortgage_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 公司治理
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮股权质押专题统计，按统计日期返回，默认不入库。

参数

参数类型必填说明默认值
datestring否统计日期，YYYYMMDD 或 YYYY-MM-DD；默认 20210930。"20210930"
limitinteger否最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
stat_datedate请求统计日期，格式 YYYYMMDD。
namestring股票简称。
announcement_datedate公告日期，格式 YYYYMMDD。
pledgorstring出质人。
pledgeestring质权人。
pledged_sharesnumber质押数量，单位/口径沿用巨潮源端。
pledged_total_share_pctnumber占总股本比例，源端百分比数值口径。
released_pledge_sharesnumber质押解除数量，单位/口径沿用巨潮源端。
pledge_eventstring质押事项。
cumulative_pledge_total_share_pctnumber累计质押占总股本比例，源端百分比数值口径。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_cg_equity_mortgage_cninfo",
    date='20210930',
    limit=1,
)
