接口文档 / 财联社

板块热门股

cls_sector_popular_stocks

临时获取财联社板块热门股数据，默认不入库。

接口信息

接口名
cls_sector_popular_stocks
Provider
axdata.source.cls
数据源
财联社 / cls
目录
财联社 / 板块数据
资产类型
stock
请求模式
source_request
采集支持
否

按财联社板块代码请求近期热门股，默认不入库。

参数

参数类型必填说明默认值
plate_codestring是板块代码，例如 cls80025。

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
secu_codestring财联社证券代码，例如 sh600000。
secu_namestring证券简称。
change_textstring涨跌幅文字。
changenumber涨跌幅数值。
change_pxnumber涨跌额。
board_tagstring连板/强势标签。
head_rankinteger龙头排名。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "cls_sector_popular_stocks",
    plate_code='cls80025',
)
