题材强度排行

stock_theme_strength_rank_tdx

按当前涨停池统计题材强度，返回涨停数量、最高板、连板股数量、封单额合计和代表股票。

接口信息

接口名
stock_theme_strength_rank_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / 短线数据
资产类型
stock
请求模式
source_request
采集支持
是，默认 stock_theme_strength_rank_tdx.snapshot

这个接口用于看当前短线题材强弱：后端复用连板天梯的涨停池口径，默认只统计主板、当前封住涨停的股票，并剔除 ST / *ST。题材强度优先看涨停数量，再看最高板、连板股数量和封单额合计。默认返回完整排行；只想取前 N 条时再传 count。

参数

参数类型必填说明默认值
countstring否返回数量；默认 all 返回完整题材排行，也可传数字只返回前 N 条，最大 500。"all"
scopestring否股票范围；默认 main 主板。可传 all、star 科创板、chinext 创业板、bse 北交所、cdr CDR，也可传数组或英文逗号分隔。"main"
topic_typestring否题材类型：theme 主题题材，sector 板块题材；默认 theme。"theme"
参数示例

# 主板完整题材强度排行 client.call("stock_theme_strength_rank_tdx") # 全市场完整题材强度排行 client.call("stock_theme_strength_rank_tdx", scope="all") # 只取前 20 个题材 client.call("stock_theme_strength_rank_tdx", count=20)

返回字段

字段类型说明
rankinteger题材排行名次。
trade_datedate排行日期，也就是这张题材强度排行对应的交易日。
topic_typestring题材类型：theme 主题题材，sector 板块题材。
topic_namestring题材名称。
topic_idstring题材 ID；源端没有给出时为空。
theme_strength_scorenumber题材强度分，用于排序；按涨停数量、最高板和连板股数量综合计算。
limit_up_countinteger题材内当前封住涨停的股票数量。
highest_ladder_levelinteger题材内最高连板高度。
lianban_stock_countinteger题材内连板股数量，指二连板及以上股票数量。
first_board_countinteger题材内首板股票数量。
leader_instrument_idstring题材内高度最高的代表股票代码。
leader_namestring题材内高度最高的代表股票简称。
leader_ladder_levelinteger代表股票连板高度。
leader_limit_board_textstring代表股票连板状态，例如 7天5板。
leader_seal_amountnumber代表股票当前封单额，单位：元。
seal_amount_sumnumber题材内涨停股封单额合计，单位：元。
amount_sumnumber题材内涨停股成交额合计，单位：元。
top_stock_summarystring题材内代表股票摘要，按连板高度和封单额排序。

参考表

排序口径

指标含义说明
涨停数量题材内当前封住涨停的股票数只统计涨停池，ST / *ST 不纳入统计
最高板题材内最高连板高度用于识别题材高度
连板股数量题材内二连板及以上股票数不是连板高度，是股票数量
强度分排序用综合分用于稳定排序；实际阅读时优先看涨停数量、最高板和连板股数量
