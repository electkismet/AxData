期货历史分时

futures_intraday_history_tdx

请求指定交易日的期货历史分时。

接口信息

接口名
futures_intraday_history_tdx
Provider
axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 期货数据
资产类型
future
请求模式
source_request
采集支持
否

请求指定交易日的期货历史分时。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
trade_datedate是交易日期，YYYYMMDD 或 YYYY-MM-DD。
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 期货历史分时 client.call("futures_intraday_history_tdx", code="IC2607.CFFEX", trade_date="20260703")

返回字段

字段类型说明
instrument_idstringAxData 统一品种代码。
symbolstring源端品种代码。
exchangestring交易所或资产场所。
namestring可确认时返回品种名称。
trade_datedate历史分时的交易日期；当日分时为空。
time_labelstring分时时间。
pricenumber分时价格或数值。
average_pricenumber分时均价或均值。
volumeinteger分时成交量，按源端口径返回。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "futures_intraday_history_tdx",
    code='IC2607.CFFEX',
    trade_date='20260703',
)
