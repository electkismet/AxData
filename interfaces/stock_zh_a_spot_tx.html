接口文档 / 腾讯财经

A股实时行情列表

stock_zh_a_spot_tx

临时获取腾讯财经A股实时行情列表数据，默认不入库。

接口信息

接口名
stock_zh_a_spot_tx
Provider
axdata.source.tencent
数据源
腾讯财经 / tencent
目录
腾讯财经 / 行情数据
资产类型
stock
请求模式
source_request
采集支持
否

临时请求腾讯财经 A 股行情排行列表，默认低页数小样本，不入库。

参数

参数类型必填说明默认值
sort_typestring否排序字段，默认 price；可选 price、change_pct、volume、amount。"price"
directionstring否排序方向：down 降序、up 升序；默认 down。"down"
offsetinteger否起始偏移量，默认 0。0
limitinteger否返回行数，默认 20，最大 200。20

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
asset_typestring资产类型，固定为 stock。
namestring证券简称。
last_pricenumber最新价，单位：元。
changenumber涨跌额，单位：元。
change_pctnumber涨跌幅，百分比数值。
amplitudenumber振幅，百分比数值。
volumenumber成交量，沿用腾讯源端口径。
amountnumber成交额，沿用腾讯源端口径。
turnover_ratenumber换手率，百分比数值。
pe_ttmnumber滚动市盈率。
total_market_valuenumber总市值，沿用腾讯源端口径。
float_market_valuenumber流通市值，沿用腾讯源端口径。
quote_statestring源端行情状态。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_zh_a_spot_tx",
    direction='down',
    limit=3,
    offset=0,
    sort_type='price',
)

Content-Type: application/json
