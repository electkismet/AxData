公告PDF元信息

cninfo_announcement_detail

确认巨潮公告 PDF 的文件类型、大小和下载地址；不解析正文。

接口信息

接口名
cninfo_announcement_detail
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 公告数据
资产类型
stock
请求模式
source_request
采集支持
否

这个接口只确认 PDF 文件类型、大小和下载地址，不解析 PDF 正文。

参数

参数类型必填说明默认值
announcement_idstring否公告 ID；可选。
urlstring是公告 PDF 路径或完整 URL。
titlestring否可选公告标题，用于透传。
参数说明

url 可以传完整 PDF 地址，也可以传巨潮返回的相对路径。

参数示例

client.call("cninfo_announcement_detail", announcement_id="1218968511", url="https://static.cninfo.com.cn/finalpage/2024-01-23/1218968511.PDF")

返回字段

字段类型说明
announcement_idstring公告 ID。
titlestring公告标题；传入时返回。
content_typestring文件类型，例如 application/pdf。
file_size_bytesinteger文件大小，单位：字节。
download_urlstringPDF 下载地址。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "cninfo_announcement_detail",
    announcement_id='1218968511',
    url='https://static.cninfo.com.cn/finalpage/2024-01-23/1218968511.PDF',
)
