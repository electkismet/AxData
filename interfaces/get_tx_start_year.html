接口文档 / 腾讯财经

腾讯历史起始日期

get_tx_start_year

临时获取腾讯财经腾讯历史起始日期数据，默认不入库。

接口信息

接口名
get_tx_start_year
Provider
axdata.source.tencent
数据源
腾讯财经 / tencent
目录
腾讯财经 / 历史行情
资产类型
stock
请求模式
source_request
采集支持
否

临时查询单个证券或指数在腾讯日线接口中的最早可用日期，默认不入库。

参数

参数类型必填说明默认值
codestring是证券或指数代码，支持 000001.SH、000001.SZ、sh000001。

返回字段

字段类型说明
instrument_idstringAxData 统一证券或指数代码。
symbolstring六位代码。
exchangestring交易所代码：SSE、SZSE、BSE。
asset_typestring资产类型：stock、index 或 etf，按代码规则推断。
start_datedate腾讯源端最早可用日期，格式 YYYYMMDD。
source_valuenumber源端首条趋势值；指数为点位，股票为价格。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "get_tx_start_year",
    code='000001.SH',
)

HTTP API

POST /v1/request/get_tx_start_year
Content-Type: application/json

{
  "params": {
    "code": "000001.SH"
  }
}
