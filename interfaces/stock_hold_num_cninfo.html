接口文档 / 巨潮

股东人数及持股集中度

stock_hold_num_cninfo

临时获取巨潮股东人数及持股集中度数据，默认不入库。

接口信息

接口名
stock_hold_num_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 股本股东
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮股东人数及持股集中度专题统计，默认不入库。

参数

参数类型必填说明默认值
datestring否报告期日期，YYYYMMDD 或 YYYY-MM-DD；默认 20210630。"20210630"

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
report_datedate请求报告期日期，格式 YYYYMMDD。
namestring证券简称。
change_datedate变动日期，格式 YYYYMMDD。
shareholder_countnumber本期股东人数，单位：户。
prev_shareholder_countnumber上期股东人数，单位：户。
shareholder_count_change_pctnumber股东人数增幅，源端百分比数值口径。
avg_holdingnumber本期人均持股数量，单位/口径沿用巨潮源端。
prev_avg_holdingnumber上期人均持股数量，单位/口径沿用巨潮源端。
avg_holding_change_pctnumber人均持股数量增幅，源端百分比数值口径。

Python SDK

import axdata as ax
