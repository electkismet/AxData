接口文档 / 腾讯财经

实时快照

tencent_realtime_snapshot

临时获取腾讯财经快照，覆盖 A 股、指数和 ETF 的确认字段。

接口信息

接口名
tencent_realtime_snapshot
Provider
axdata.source.tencent
数据源
腾讯财经 / tencent
目录
腾讯财经 / 行情数据
资产类型
stock
请求模式
source_request
采集支持
否

这个接口返回源端快照时间；价格单位为元或指数点，比例字段是百分比数值。

参数

参数类型必填说明默认值
codestring是证券代码，支持 000001.SZ、600000.SH、920000.BJ、000001.SH、510050.SH 或列表。
参数说明

不传 fields 时返回上方全部字段；临时调用只查一次。

参数示例

client.call("tencent_realtime_snapshot", code=["000001.SZ", "600000.SH"])

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
asset_typestring资产类型：stock、index、etf。
namestring证券简称。
quote_timedatetime源端行情时间，格式 YYYYMMDDHHMMSS。
last_pricenumber最新价，单位：元或指数点。
pre_closenumber昨收价，单位：元或指数点。
opennumber开盘价，单位：元或指数点。
highnumber最高价，单位：元或指数点。
lownumber最低价，单位：元或指数点。
changenumber涨跌额，单位：元或指数点。
change_pctnumber涨跌幅，百分比数值。
volumenumber成交量，沿用源端口径。
amountnumber成交额，单位：元。
turnover_ratenumber换手率，百分比数值；指数可能为空。
pe_dynamicnumber动态市盈率；不适用时为空。
pbnumber市净率；不适用时为空。
total_market_valuenumber总市值，源端确认口径为亿元。
float_market_valuenumber流通市值，源端确认口径为亿元。
limit_up_pricenumber涨停价；不适用时为空。
limit_down_pricenumber跌停价；不适用时为空。
currencystring币种。

调用示例

Python SDK

client = ax.AxDataClient()
rows = client.call(
    "tencent_realtime_snapshot",
    code=['000001.SZ', '600000.SH'],
)
