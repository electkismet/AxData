新浪期货主力连续展示

futures_display_main_sina

临时获取新浪财经新浪期货主力连续展示数据，默认不入库。

接口信息

接口名
futures_display_main_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期货行情
资产类型
future
请求模式
source_request
采集支持
否

临时请求新浪期货单品种节点主力连续候选行情，默认不入库。

参数

参数类型必填说明默认值
nodestring否新浪期货品种节点，例如 lwg_qh（螺纹钢）；默认 lwg_qh。"lwg_qh"
pageinteger否页码，默认 1。1
limitinteger否当前页最多返回行数，默认 5，最大 100。5

返回字段

字段类型说明
rankinteger源端排序序号，从 1 开始。
source_nodestring新浪期货品种节点，例如 lwg_qh。
source_symbolstring新浪期货合约代码，例如 RB0。
exchangestring源端交易所代码，例如 shfe、czce、dce、cffex、gfex。
namestring合约名称。
trade_datedate交易日期，格式 YYYYMMDD。
tick_timestring行情时间。
last_pricenumber最新价。
opennumber开盘价。
highnumber最高价。
lownumber最低价。
closenumber收盘价/源端 close。
preclosenumber昨收价。
settlementnumber结算价。
prev_settlementnumber昨结算价。
bid_price_1number买一价。
ask_price_1number卖一价。
bid_volume_1number买一量。
ask_volume_1number卖一量。
volumenumber成交量。
open_interestnumber持仓量。
change_pctnumber涨跌幅，源端小数口径。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "futures_display_main_sina",
    limit=1,
    node='lwg_qh',
    page=1,
)

HTTP API

POST /v1/request/futures_display_main_sina
Content-Type: application/json

{
  "params": {
    "node": "lwg_qh",
    "page": 1,
    "limit": 1
  }
}
