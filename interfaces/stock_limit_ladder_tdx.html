连板天梯

stock_limit_ladder_tdx

获取当前连板天梯，默认返回主板完整天梯，返回连板高度、连板状态、封单额、流通市值Z、主题材和辅助题材。

接口信息

接口名
stock_limit_ladder_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / 短线数据
资产类型
stock
请求模式
source_request
采集支持
是，默认 stock_limit_ladder_tdx.snapshot

这个接口用于短线看盘：后端实时扫描当前 A 股涨幅榜，按涨跌停规则判断封板状态，再结合盘前统计资源计算连板高度、几天几板和年涨停天数。默认只统计主板，ST / *ST 不纳入连板天梯和题材涨停数量统计；需要创业板、科创板、北交所等范围时传 scope。默认返回完整天梯；只想取前 N 条时再传 count。题材会先过滤持股、指数、定增、宽泛标签等噪音项，再优先按题材内涨停数排序，其次看最高板、连板数和个股关联度，主题材取一个，辅助题材最多取三个。

参数

参数类型必填说明默认值
countstring否返回数量；默认 all 返回完整天梯，也可传数字只返回前 N 条，最大 500。"all"
scopestring否股票范围；默认 main 主板。可传 all、star 科创板、chinext 创业板、bse 北交所、cdr CDR，也可传数组或英文逗号分隔。"main"
include_touchedboolean否是否包含盘中触及涨停但当前未封住的股票；默认 false，只返回当前封住涨停的股票。false
topic_typestring否题材类型：theme 主题题材，sector 板块题材；默认 theme。"theme"
参数示例

# 主板完整连板天梯 client.call("stock_limit_ladder_tdx") # 全市场完整连板天梯 client.call("stock_limit_ladder_tdx", scope="all") # 同时包含触及涨停但当前未封住的股票 client.call("stock_limit_ladder_tdx", include_touched=True) # 只取前 20 条 client.call("stock_limit_ladder_tdx", count=20)

返回字段

字段类型说明
trade_datedate天梯日期，也就是这张连板天梯对应的交易日。
ladder_levelinteger当前连板高度；封住涨停时按历史连板数加今天计算。
limit_board_textstring连板状态，也就是几天几板，例如 7天5板。
instrument_idstringAxData 统一证券代码，例如 000001.SZ。
namestring证券简称。
last_pricenumber最新价，单位：元。
change_pctnumber当前涨跌幅，百分比数值。
limit_statusstring涨停状态：sealed 当前封住涨停；touched 盘中触及涨停但当前未封住。
amountnumber当前成交额，单位：元。
seal_amountnumber当前封单额，单位：元。
seal_to_amount_rationumber封成比，按封单额 / 当前成交额计算。
free_float_market_valuenumber流通市值Z，按流通股本Z * 当前价计算，单位：元。
primary_themestring主题材；过滤噪音题材后，优先按题材内涨停数排序，其次看最高板、连板数和个股关联度，取排序第一的一个题材。
secondary_themesstring辅助题材；从主题材之后的有效题材中最多取三个，用 + 连接。
year_limit_up_daysinteger年内涨停天数。
symbolstring交易所原始六位代码。
exchangestringAxData 交易所代码：SSE、SZSE 或 BSE。
pre_closenumber昨收价，单位：元。
limit_up_pricenumber按昨收价和涨跌停规则计算的涨停价，单位：元。

参考表

涨停状态

状态含义说明
sealed当前封住涨停最新价在涨停价，且买一/封单能确认仍封住
touched触及涨停但未封住盘中最高价到过涨停价，但当前没有按封住涨停处理

题材排序

字段含义说明
primary_theme主题材过滤噪音题材后，优先按题材内涨停数排序，其次看最高板、连板数和个股关联度，取排序第一的题材
secondary_themes辅助题材主题材之后最多三个题材，用 + 连接
过滤项不适合作为短线题材的标签例如持股、指数成分、定增、融资融券、财报等宽泛或属性类标签
题材强度题材统计指标涨停数量、最高板、连板股数量等详细指标请看题材强度排行接口
