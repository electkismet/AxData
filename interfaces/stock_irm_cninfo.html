接口文档 / 巨潮

互动易提问

stock_irm_cninfo

临时获取巨潮互动易提问数据，默认不入库。

接口信息

接口名
stock_irm_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 互动易
资产类型
stock
请求模式
source_request
采集支持
否

临时请求互动易提问列表，默认不入库。

参数

参数类型必填说明默认值
codestring是股票代码，支持 002594、002594.SZ。
pageinteger否页码，默认 1。1
limitinteger否每页条数，默认 30，最大 1000。30
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；可选。
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；可选。
keywordstring否关键词；可选。

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring公司简称。
industrystring源端行业名称。
industry_codestring源端行业代码。
question_idstring互动易问题编号。
questionstring提问内容。
questionerstring提问者。
questioner_idstring提问者编号。
sourcestring提问来源：APP、公众号、网站等。
question_timedatetime提问时间，Asia/Shanghai，格式 YYYYMMDDHHMMSS。
update_timedatetime更新时间，Asia/Shanghai，格式 YYYYMMDDHHMMSS。
answer_idstring已关联回答 ID；未回答时为空。
answerstring已关联回答内容；未回答时为空。
answererstring回答者；未回答时为空。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_irm_cninfo",
    code='002594.SZ',
    limit=1,
    page=1,
)
