concept_related_boards_tdx

查询个股当前关联板块列表。

接口信息

接口名
concept_related_boards_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / 短线数据
资产类型
stock
请求模式
source_request
采集支持
否

查询个股当前关联板块列表。

参数

参数类型必填说明默认值
codestring是股票代码：支持 000001、000001.SZ、sz000001；批量可传列表或英文逗号分隔字符串。
参数说明

不传时间；按 code 返回该股票当前关联板块列表。

参数示例

# 单个标的 client.call("concept_related_boards_tdx", code="000001.SZ") # 批量请求多个标的 client.call("concept_related_boards_tdx", code=["000034.SZ", "000001.SZ"])

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码，例如 000001.SZ。
symbolstring交易所原始六位代码。
board_marketstring板块市场。
board_codestring板块代码。
board_namestring板块名称。
change_pctnumber涨幅，单位：%。
limit_up_countinteger涨停数。
