接口文档 / 开盘红

历史跌停股

kph_limit_down_history

临时获取开盘红历史跌停股数据，默认不入库。

接口信息

接口名
kph_limit_down_history
Provider
axdata.source.kph
数据源
开盘红 / kph
目录
开盘红 / 短线数据
资产类型
stock
请求模式
source_request
采集支持
否

请求开盘红历史跌停股列表，默认不入库。

参数

参数类型必填说明默认值
trade_datestring是历史交易日期，必须早于今天。

返回字段

字段类型说明
trade_datedate交易日期，格式 YYYYMMDD。
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring股票简称。
limit_timeinteger涨停/跌停时间戳。
open_timeinteger开板时间戳，0 表示未开。
seal_amountnumber封单量。
seal_moneynumber封单金额，单位：元。
limit_tagstring连板标签。
limit_countinteger连板数。
themesstring题材。
reasonstring涨停原因。
net_inflownumber净流入，单位：元。
turnovernumber成交额，单位：元。
turnover_ratenumber换手率，百分比数值。
market_capnumber流通市值，单位：元。
industry_idstring行业 ID。
industry_limit_up_countinteger同行业涨停数。

Python SDK

import axdata as ax

client = ax.AxDataClient()

    trade_date='20260513',
)
