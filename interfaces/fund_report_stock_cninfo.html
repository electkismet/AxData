接口文档 / 巨潮

基金重仓股

fund_report_stock_cninfo

临时获取巨潮基金重仓股数据，默认不入库。

接口信息

接口名
fund_report_stock_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 基金报表
资产类型
fund
请求模式
source_request
采集支持
否

临时请求巨潮基金重仓股专题统计，按报告期返回，默认不入库。

参数

参数类型必填说明默认值
datestring否报告期日期，YYYYMMDD 或 YYYY-MM-DD；通常为季末日期，默认 20210630。"20210630"
limitinteger否最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码；若源端不是六位 A 股代码则为空。
symbolstring证券代码。
exchangestring交易所代码：SSE、SZSE、BSE；无法识别时为空。
record_idstring源端记录序号。
namestring股票简称。
report_datedate报告期，格式 YYYYMMDD。
fund_countnumber基金覆盖家数，单位：只。
holding_sharesnumber持股总数，单位/口径沿用巨潮源端。
holding_market_valuenumber持股总市值，金额单位/口径沿用巨潮源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "fund_report_stock_cninfo",
    date='20210630',
    limit=1,
)

HTTP API

POST /v1/request/fund_report_stock_cninfo
Content-Type: application/json

{
  "params": {
    "date": "20210630",
    "limit": 1
  }
}
