最新ST股票列表

stock_st_list_tdx

默认扫描通达信全市场股票池，返回当前 ST / *ST 股票。

接口信息

接口名
stock_st_list_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / 基础数据
资产类型
stock
请求模式
source_request
采集支持
是，默认 stock_st_list_tdx.snapshot

这个接口默认扫全市场股票池，只返回当前名称带 ST / *ST 的股票；默认不写本地数据。

参数

参数类型必填说明默认值
namestring否股票简称：例如 平安银行、浦发银行。
codestring否股票代码：支持 000001、000001.SZ、sz000001。
scopestring否股票范围：all 全部、main 主板、star 科创板、chinext 创业板、bse 北交所、cdr CDR；默认 all。"all"
参数说明

不传参数时，默认扫描全市场并返回当前 ST / *ST 股票列表。

参数示例

# 默认扫描全市场当前 ST / *ST 股票 client.call("stock_st_list_tdx") # 调试指定股票 client.call("stock_st_list_tdx", code=["000004.SZ", "002102.SZ"])

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码，例如 000004.SZ。
symbolstring交易所原始六位代码。
tdx_codestringTDX 带市场前缀代码，例如 sz000004。
exchangestringAxData 交易所代码：SSE、SZSE 或 BSE。
namestring证券简称。
marketstring按规则识别的板块名称。
st_typestring识别出的 ST 类型：ST 或 *ST。
