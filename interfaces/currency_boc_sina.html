新浪中行外汇牌价

currency_boc_sina

临时获取新浪财经新浪中行外汇牌价数据，默认不入库。

接口信息

接口名
currency_boc_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 外汇
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪中行人民币牌价历史页单页，默认不入库。

参数

参数类型必填说明默认值
symbolstring否货币中文名称或代码，例如 美元、USD；默认 美元。"美元"
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；默认 20230304。"20230304"
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；默认 20230310。"20230310"
pageinteger否页码，默认 1。1
limitinteger否当前页最多返回行数，默认 20，最大 100。20

返回字段

字段类型说明
currency_codestring货币代码，例如 USD。
currency_namestring货币中文名称。
quote_datedate牌价日期，格式 YYYYMMDD。
fx_buy_ratenumber中行汇买价，单位：人民币元/100 外币。
cash_buy_ratenumber中行钞买价，单位：人民币元/100 外币。
cash_sell_ratenumber中行钞卖价/汇卖价，单位：人民币元/100 外币。
pboc_mid_ratenumber央行中间价，单位：人民币元/100 外币。
boc_conversion_ratenumber中行折算价，单位：人民币元/100 外币。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "currency_boc_sina",
    end_date='20230310',
    limit=1,
    start_date='20230304',
    symbol='美元',
)
