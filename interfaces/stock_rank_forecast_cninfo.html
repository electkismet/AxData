接口文档 / 巨潮

投资评级

stock_rank_forecast_cninfo

临时获取巨潮投资评级数据，默认不入库。

接口信息

接口名
stock_rank_forecast_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 评级预测
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮投资评级专题统计，按日期返回，默认不入库。

参数

参数类型必填说明默认值
datestring否查询日期，YYYYMMDD 或 YYYY-MM-DD；默认 20230817。"20230817"
limitinteger否最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
publish_datedate发布日期，格式 YYYYMMDD。
institution_short_namestring研究机构简称。
analyst_namestring研究员名称。
ratingstring投资评级。
is_first_ratingstring是否首次评级，沿用巨潮源端文本。
rating_changestring评级变化。
previous_ratingstring前一次投资评级。
target_price_lownumber目标价格下限，单位：元。
target_price_highnumber目标价格上限，单位：元。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_rank_forecast_cninfo",
    date='20230817',
    limit=1,
)
