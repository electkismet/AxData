五档盘口

stock_order_book_tdx

获取当前五档盘口快照，返回买一到买五、卖一到卖五的价格和量。

接口信息

接口名
stock_order_book_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / 实时数据
资产类型
stock
请求模式
source_request
采集支持
否

这个接口按股票代码请求当前盘口快照，每个标的一般返回 5 行，一行对应一个盘口档位。

参数

参数类型必填说明默认值
codestring是证券代码：支持 000001、000001.SZ、sz000001；批量可传列表或英文逗号分隔字符串。
参数示例

# 单个标的 client.call("stock_order_book_tdx", code="000001.SZ") # 批量请求多个标的 client.call("stock_order_book_tdx", code=["000001.SZ", "600000.SH"])

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码，例如 000001.SZ。
symbolstring交易所原始六位代码。
tdx_codestringTDX 带市场前缀代码，例如 sz000001。
exchangestringAxData 交易所代码：SSE、SZSE 或 BSE。
levelinteger盘口档位，1 到 5。
bid_pricenumber该档委买价。
bid_volumeinteger该档委买量，A 股常见口径为手。
ask_pricenumber该档委卖价。
ask_volumeinteger该档委卖量，A 股常见口径为手。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_order_book_tdx",
    code='000001.SZ',
)

HTTP API

POST /v1/request/stock_order_book_tdx
Content-Type: application/json

  }
