接口文档 / 巨潮

国债发行

bond_treasure_issue_cninfo

临时获取巨潮国债发行数据，默认不入库。

接口信息

接口名
bond_treasure_issue_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 债券报表
资产类型
bond
请求模式
source_request
采集支持
否

临时请求巨潮国债发行专题统计，按日期范围返回，默认不入库。

参数

参数类型必填说明默认值
start_datestring否开始统计日期，YYYYMMDD 或 YYYY-MM-DD；默认 20210910。"20210910"
end_datestring否结束统计日期，YYYYMMDD 或 YYYY-MM-DD；默认 20211109。"20211109"
limitinteger否最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
bond_codestring债券代码。
bond_short_namestring债券简称。
issue_start_datedate发行起始日，格式 YYYYMMDD。
issue_end_datedate发行终止日，格式 YYYYMMDD。
planned_issue_amountnumber计划发行总量，单位/口径沿用巨潮源端。
actual_issue_amountnumber实际发行总量，单位/口径沿用巨潮源端。
issue_pricenumber发行价格，单位：元。
par_valuenumber单位面值，单位：元。
payment_datedate缴款日，格式 YYYYMMDD。
additional_issue_countnumber增发次数，源端数值口径。
trading_marketstring交易市场。
issue_methodstring发行方式。
issue_targetstring发行对象。
announcement_datedate公告日期，格式 YYYYMMDD。
bond_namestring债券名称。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "bond_treasure_issue_cninfo",
    end_date='20211109',
    limit=1,
    start_date='20210910',
)
