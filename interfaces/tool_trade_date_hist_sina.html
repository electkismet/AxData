新浪交易日历

tool_trade_date_hist_sina

临时获取新浪财经新浪交易日历数据，默认不入库。

接口信息

接口名
tool_trade_date_hist_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 交易日历
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪 KLC_TD_SH 交易日历文本并用纯 Python 解码，默认不入库。

参数

参数类型必填说明默认值
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；默认不限制。
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；默认不限制。
limitinteger否最多返回行数，默认 100，最大 10000。100

返回字段

字段类型说明
trade_datedate交易日期，格式 YYYYMMDD。
exchangestring交易所代码；新浪源端为上交所交易日历，固定 SSE。
is_openboolean是否交易日；该接口仅返回交易日，固定 true。
source_calendarstring源端日历标识。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "tool_trade_date_hist_sina",
    limit=1,
    start_date='19901219',
)
