交易日历

stock_trade_calendar_exchange

从深交所官方交易日历返回指定日期范围内的开闭市信息。

接口信息

接口名
stock_trade_calendar_exchange
Provider
axdata.source.exchange
数据源
交易所 / exchange
目录
交易所 / 基础数据
资产类型
stock
请求模式
source_request
采集支持
是，默认 stock_trade_calendar_exchange.snapshot

不传日期时默认返回当前自然年；传 year 返回全年；传 start_date/end_date 返回指定范围。

参数

参数类型必填说明默认值
yearstring否年份，例如 2026；传 start_date/end_date 时优先按日期范围查询。
start_datestring否开始日期，格式 YYYYMMDD 或 YYYY-MM-DD。
end_datestring否结束日期，格式 YYYYMMDD 或 YYYY-MM-DD。
参数说明

日期优先级：start_date/end_date > year > 当前自然年。

参数示例

# 指定日期范围 client.call( "stock_trade_calendar_exchange", start_date="20260617", end_date="20260622", ) # 指定年份 client.call("stock_trade_calendar_exchange", year=2026) # 不传日期，默认当前自然年 client.call("stock_trade_calendar_exchange")

返回字段

字段类型说明
cal_datedate自然日期，格式 YYYYMMDD。
is_openboolean是否交易日。
pretrade_datedate上一个交易日；非交易日也返回最近上一交易日。
next_trade_datedate下一个交易日；非交易日也返回最近下一交易日。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_trade_calendar_exchange",
    end_date='20260622',
    start_date='20260617',
)
