接口文档 / 巨潮

公司概况

stock_profile_cninfo

临时获取巨潮公司概况数据，默认不入库。

接口信息

接口名
stock_profile_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 公司资料
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮公司概况 webapi，返回单家公司资料，默认不入库。

参数

参数类型必填说明默认值
codestring是股票代码，支持 600030、600030.SH。

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
company_namestring公司全称。
english_namestring英文名称。
former_short_namestring曾用简称。
a_share_codestringA 股代码。
a_share_namestringA 股简称。
b_share_codestringB 股代码。
b_share_namestringB 股简称。
h_share_codestringH 股代码。
h_share_namestringH 股简称。
selected_indexesstring入选指数，沿用巨潮源端文本。
marketstring所属市场。
industrystring所属行业。
legal_representativestring法人代表。
registered_capitalnumber注册资金，沿用巨潮源端单位/口径。
founded_datedate成立日期，格式 YYYYMMDD。
listing_datedate上市日期，格式 YYYYMMDD。
websitestring官方网站。
emailstring电子邮箱。
phonestring联系电话。
faxstring传真。
registered_addressstring注册地址。
office_addressstring办公地址。
postcodestring邮政编码。
main_businessstring主营业务。
business_scopestring经营范围。
organization_profilestring机构简介。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_profile_cninfo",
    code='600030.SH',
)

HTTP API

POST /v1/request/stock_profile_cninfo
Content-Type: application/json

{
  "params": {
    "code": "600030.SH"
  }
}
