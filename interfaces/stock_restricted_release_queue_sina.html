新浪限售解禁批次

stock_restricted_release_queue_sina

临时获取新浪财经新浪限售解禁批次数据，默认不入库。

接口信息

接口名
stock_restricted_release_queue_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 发行分配
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪单证券限售解禁表，默认不入库。

参数

参数类型必填说明默认值
symbolstring否股票代码、AxData 证券代码或新浪代码，例如 sh600000；默认 sh600000。"sh600000"
limitinteger否最多返回行数，默认 100，最大 5000。100

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位股票代码。
sina_symbolstring新浪带市场前缀代码，例如 sh600000。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring股票名称。
release_datedate解禁日期，格式 YYYYMMDD。
release_shares_10knumber解禁数量，单位：万股。
release_market_value_100m_yuannumber解禁股流通市值，单位：亿元。
batch_nointeger上市批次。
announcement_datedate公告日期，格式 YYYYMMDD。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_restricted_release_queue_sina",
    limit=1,
    symbol='sh600000',
)

POST /v1/request/stock_restricted_release_queue_sina
Content-Type: application/json

{
  "params": {
    "symbol": "sh600000",
    "limit": 1
  }
}
