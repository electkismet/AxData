新浪全球财经快讯

stock_info_global_sina

临时获取新浪财经新浪全球财经快讯数据，默认不入库。

接口信息

接口名
stock_info_global_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 资讯快讯
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪 7x24 全球财经快讯单页，默认不入库。

参数

参数类型必填说明默认值
pageinteger否页码，默认 1。1
page_sizeinteger否源端每页条数，默认 20，最大 100。20
limitinteger否最多返回行数，默认等于 page_size，最大不超过 page_size。20
zhibo_idstring否新浪直播频道 ID；默认 152，对应全球财经快讯。"152"
tag_idstring否新浪直播标签 ID；默认 0，表示全部标签。"0"

返回字段

字段类型说明
feed_idstring新浪快讯源端 ID，可能为空。
create_timedatetime快讯发布时间，源端时间字符串。
contentstring快讯正文，已去除简单 HTML 标签。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_info_global_sina",
    limit=1,
    page=1,
    page_size=2,
)

POST /v1/request/stock_info_global_sina
Content-Type: application/json

{
