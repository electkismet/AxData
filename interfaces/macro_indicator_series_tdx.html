宏观指标序列

macro_indicator_series_tdx

请求宏观指标序列，返回日期和值；单位未确认时保持为空。

接口信息

接口名
macro_indicator_series_tdx

axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 宏观数据
资产类型
macro
请求模式
source_request
采集支持
否

请求宏观指标序列，返回日期和值；单位未确认时保持为空。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
periodstring否K线周期：1m、5m、15m、30m、60m、day、week、month、quarter、year；默认 day。"day"
limitinteger否每个品种返回前多少根，默认 30。30
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 宏观指标序列 client.call("macro_indicator_series_tdx", code="1_GDP.MACRO", period="day", limit=3)

返回字段

字段类型说明
indicator_idstringAxData 宏观指标代码。
symbolstring源端指标代码。
namestring可确认时返回指标名称。
period_datedate指标期日期。
periodstring序列周期。
valuenumber本期值。
opennumber开值；源端有值时返回。
highnumber高值；源端有值时返回。
lownumber低值；源端有值时返回。
unitstring单位；未确认时为空。
frequencystring发布频度；未确认时为空。
