接口文档 / 新浪财经

新浪股票分类成份

stock_classify_sina

临时获取新浪财经新浪股票分类成份数据，默认不入库。

接口信息

接口名
stock_classify_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 股票分类
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪行情中心单个股票分类节点的单页行情，默认不入库；不按 AkShare 参考实现全分类全页拉取。

参数

参数类型必填说明默认值
symbolstring否分类组别别名，例如 新浪行业、热门概念；仅用于结果标注，默认 新浪行业。"新浪行业"
categorystring否分类组别名称；优先级高于 symbol，仅用于结果标注。
class_namestring否分类名称，仅用于结果标注；默认 玻璃行业。"玻璃行业"
nodestring否新浪分类节点代码，例如 new_blhy；默认 new_blhy。"new_blhy"
pageinteger否页码，默认 1。1
limitinteger否每页条数/最多返回行数，默认 80，最大 3000。80

返回字段

字段类型说明
categorystring分类组别，例如 新浪行业、热门概念；由请求参数标注。
class_namestring分类名称，例如 玻璃行业；由请求参数标注。
source_nodestring新浪行情中心分类节点代码，例如 new_blhy。
rankinteger当前请求页内展开后的全局序号。
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
sina_symbolstring新浪带市场前缀代码，例如 sh600000。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
latest_pricenumber最新价，单位：元。
changenumber涨跌额，单位：元。
change_pctnumber涨跌幅，源端百分比数值口径。
bidnumber买入价，单位：元。
asknumber卖出价，单位：元。
prev_closenumber昨收，单位：元。
opennumber今开，单位：元。
highnumber最高价，单位：元。
lownumber最低价，单位：元。
volumenumber成交量，单位/口径沿用新浪源端。
amountnumber成交额，金额单位/口径沿用新浪源端。
tick_timestring源端行情时间。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_classify_sina",
    class_name='玻璃行业',
    limit=1,
    node='new_blhy',
)

POST /v1/request/stock_classify_sina
Content-Type: application/json

{
  "params": {
    "node": "new_blhy",
    "class_name": "玻璃行业",
    "limit": 1
  }
}
