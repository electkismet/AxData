新浪中金所上证50期权日线

option_cffex_sz50_daily_sina

临时获取新浪财经新浪中金所上证50期权日线数据，默认不入库。

接口信息

接口名
option_cffex_sz50_daily_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期权
资产类型
option
请求模式
source_request
采集支持
否

临时请求新浪中金所上证50指数期权单合约日线，默认不入库。

参数

参数类型必填说明默认值
symbolstring否中金所上证50期权合约代码，例如 ho2303P2350；默认 ho2303P2350。"ho2303P2350"
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
limitinteger否最多返回行数，默认 100，最大 5000。100

返回字段

字段类型说明
source_symbolstring新浪中金所期权合约代码，例如 io2202P4350。
underlying_namestring期权标的指数名称，例如 沪深300指数。
option_typestring期权类型：看涨期权或看跌期权。
exercise_pricenumber行权价，单位：指数点。
trade_datedate交易日期，格式 YYYYMMDD。
opennumber开盘价，单位：点。
highnumber最高价，单位：点。
lownumber最低价，单位：点。
closenumber收盘价，单位：点。
volumenumber成交量，单位/口径沿用新浪源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "option_cffex_sz50_daily_sina",
    limit=1,
    symbol='ho2303P2350',
)
