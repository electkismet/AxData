新浪秩鼎 ESG 评分

stock_esg_zd_sina

临时获取新浪财经新浪秩鼎 ESG 评分数据，默认不入库。

接口信息

接口名
stock_esg_zd_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / ESG
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪 ESG 评级中心秩鼎评分单页小样本，默认不入库。

参数

参数类型必填说明默认值
pageinteger否页码，默认 1。1
limitinteger否最多返回行数，默认 20，最大 100；不会按 AkShare 参考实现全量拉取。20

返回字段

字段类型说明
symbolstring源端股票代码。
esg_scorenumber秩鼎 ESG 综合评分。
env_scorenumber环境维度评分。
social_scorenumber社会责任维度评分。
governance_scorenumber公司治理维度评分。
report_datedate评分日期，格式 YYYYMMDD。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_esg_zd_sina",
    limit=1,
    page=1,
)
