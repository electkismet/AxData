新浪期货主力连续日线

futures_main_sina

临时获取新浪财经新浪期货主力连续日线数据，默认不入库。

接口信息

接口名
futures_main_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期货行情
资产类型
future
请求模式
source_request
采集支持
否

临时请求新浪期货单个主力连续合约日线小窗口，默认不入库。

参数

参数类型必填说明默认值
symbolstring否新浪主力连续合约代码，例如 CF0、RB0；默认 CF0。"CF0"
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；默认 20240124。"20240124"
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；默认 20240301。"20240301"
limitinteger否最多返回行数，默认 100，最大 10000。100

返回字段

字段类型说明
source_symbolstring新浪主力连续合约代码，例如 CF0。
trade_datedate交易日期，格式 YYYYMMDD。
opennumber开盘价。
highnumber最高价。
lownumber最低价。
closenumber收盘价。
volumenumber成交量，单位：手。
open_interestnumber持仓量，单位：手。
settlementnumber动态结算价。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "futures_main_sina",
    end_date='20240301',
    limit=1,
    start_date='20240124',
    symbol='CF0',
)

POST /v1/request/futures_main_sina
Content-Type: application/json
