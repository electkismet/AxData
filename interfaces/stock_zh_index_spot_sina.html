接口文档 / 新浪财经

A 股指数实时行情

stock_zh_index_spot_sina

临时获取新浪财经A 股指数实时行情数据，默认不入库。

接口信息

接口名
stock_zh_index_spot_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 指数数据
资产类型
index
请求模式
source_request
采集支持
否

临时请求新浪行情中心 A 股指数单页，默认不入库。

参数

参数类型必填说明默认值
pageinteger否页码，默认 1。1
limitinteger否当前页最多返回行数，默认 80，最大 80。80

返回字段

字段类型说明
instrument_idstringAxData 统一指数代码。
symbolstring六位指数代码。
sina_symbolstring新浪带市场前缀代码，例如 sh000001。
exchangestring交易所代码：SSE、SZSE。
asset_typestring资产类型，固定为 index。
namestring指数名称。
latest_pricenumber最新点位。
changenumber涨跌额。
change_pctnumber涨跌幅，源端百分比数值口径。
bidnumber买入价，指数通常为 0。
asknumber卖出价，指数通常为 0。
prev_closenumber昨收点位。
opennumber今开点位。
highnumber最高点位。
lownumber最低点位。
volumenumber成交量，沿用新浪源端指数口径。
amountnumber成交额，沿用新浪源端指数口径。
tick_timestring源端行情时间。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_zh_index_spot_sina",
    limit=1,
    page=1,
)

HTTP API

POST /v1/request/stock_zh_index_spot_sina
Content-Type: application/json

{
  "params": {
    "page": 1,
    "limit": 1
  }
}
