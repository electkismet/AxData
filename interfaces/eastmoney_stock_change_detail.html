接口文档 / 东方财富

个股盘口异动明细

eastmoney_stock_change_detail

临时获取东方财富个股盘口异动明细数据，默认不入库。

接口信息

接口名
eastmoney_stock_change_detail
Provider
axdata.source.eastmoney
数据源
东方财富 / eastmoney
目录
东方财富 / 短线数据
资产类型
stock
请求模式
source_request
采集支持
否

请求单只股票盘口异动明细，默认不入库。

参数

参数类型必填说明默认值
codestring是股票代码，支持 000001.SZ。
marketstring否东方财富市场代码，0=深/北，1=沪；不传则按代码推断。
trade_datestring否交易日期，YYYYMMDD 或 YYYY-MM-DD，默认今天。

返回字段

字段类型说明
trade_datedate交易日期。
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
market_codestring东方财富市场代码。
change_timestring异动时间，HHMMSS。
change_typestring异动类型编码。
change_type_namestring异动类型名称。
pricenumber价格，单位：元。
change_pctnumber涨跌幅，百分比数值。
volumenumber成交量，源端口径。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "eastmoney_stock_change_detail",
    code='301520.SZ',
    trade_date='20260703',
)

HTTP API

POST /v1/request/eastmoney_stock_change_detail
Content-Type: application/json

{
  "params": {
    "code": "301520.SZ",
    "trade_date": "20260703"
  }
}
