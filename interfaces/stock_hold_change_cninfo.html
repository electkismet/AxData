接口文档 / 巨潮

股本变动

stock_hold_change_cninfo

临时获取巨潮股本变动数据，默认不入库。

接口信息

接口名
stock_hold_change_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 股本股东
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮股本变动专题统计，返回所选市场的股本变动行，默认不入库。

参数

参数类型必填说明默认值
marketstring否市场范围：深市主板、沪市、创业板、科创板、北交所、全部；默认 沪市。源端全部口径可能返回 403。"沪市"

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
trade_marketstring交易市场。
namestring证券简称。
announcement_datedate公告日期，格式 YYYYMMDD。
change_datedate变动日期，格式 YYYYMMDD。
change_reasonstring变动原因。
total_sharenumber总股本，单位/口径沿用巨潮源端。
circulated_sharenumber已流通股份，单位/口径沿用巨潮源端。
circulated_rationumber已流通比例，源端数值口径。
restricted_sharenumber流通受限股份，单位/口径沿用巨潮源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_hold_change_cninfo",
    market='沪市',
)

POST /v1/request/stock_hold_change_cninfo
Content-Type: application/json

{
  "params": {

  }
