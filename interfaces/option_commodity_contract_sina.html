新浪商品期权品种列表

option_commodity_contract_sina

临时获取新浪财经新浪商品期权品种列表数据，默认不入库。

接口信息

接口名
option_commodity_contract_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期权
资产类型
option
请求模式
source_request
采集支持
否

临时请求新浪商品期权品种入口列表，默认不入库。

参数

参数类型必填说明默认值
limitinteger否最多返回品种数，默认 100，最大 200。100

返回字段

字段类型说明
sequenceinteger源端顺序，从 1 开始。
option_namestring商品期权品种名称，例如豆粕期权。
product_codestring新浪商品期权品种代码，例如 m_o、pg_o。
exchangestring源端交易所代码，例如 dce、czce、shfe、gfex。
source_pathstring新浪商品期权页面相对路径。
source_urlstring新浪商品期权页面完整 URL。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "option_commodity_contract_sina",
    limit=1,
)
