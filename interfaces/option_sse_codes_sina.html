接口文档 / 新浪财经

上交所期权代码发现

option_sse_codes_sina

临时获取新浪财经上交所期权代码发现数据，默认不入库。

接口信息

接口名
option_sse_codes_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期权行情
资产类型
option
请求模式
source_request
采集支持
否

临时请求新浪上交所期权合约代码列表，默认不入库。

参数

参数类型必填说明默认值
symbolstring否期权方向：看涨期权、看跌期权；也兼容 call、put；默认 看涨期权。"看涨期权"
trade_datestring否合约到期月份，YYYYMM 或 YYYY-MM；不传时取源端最近到期月份。
underlyingstring否期权标的代码或分类：510050/50ETF、510300/300ETF、510500/500ETF、588000/科创50、588080/科创板50；默认 510050。"510050"
limitinteger否最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
sequenceinteger源端列表顺序，从 1 开始。
option_codestring上交所期权合约数字代码。
sina_symbolstring新浪期权行情代码，例如 CON_OP_10011799。
option_typestring期权方向：看涨期权或看跌期权。
underlyingstring期权标的证券代码，例如 510050。
underlying_namestring期权标的源端分类名称，例如 50ETF。
expire_monthstring合约到期月份，格式 YYYYMM。
exchangestring交易所代码；上交所期权为 SSE。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "option_sse_codes_sina",
    limit=1,
    symbol='看涨期权',

    underlying='510050',
