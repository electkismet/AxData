新浪美国国债收益率

bond_gb_us_sina

临时获取新浪财经新浪美国国债收益率数据，默认不入库。

接口信息

接口名
bond_gb_us_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 债券收益率
资产类型
bond
请求模式
source_request
采集支持
否

临时请求新浪美国国债收益率日线 JSON，默认不入库。

参数

参数类型必填说明默认值
symbolstring否美国国债期限名称或新浪代码，例如 美国10年期国债、US10YT；默认 美国10年期国债。"美国10年期国债"
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
limitinteger否最多返回行数，默认最近 100 行，最大 10000。100

返回字段

字段类型说明
source_symbolstring新浪国债收益率代码，例如 US10YT。
symbol_namestring中文期限名称，例如 美国10年期国债。
countrystring国家/地区代码：US 或 CN。
tenorstring期限代码，例如 10Y、6M。
trade_datedate交易日期，格式 YYYYMMDD。
open_yieldnumber开盘收益率，单位：%。
high_yieldnumber最高收益率，单位：%。
low_yieldnumber最低收益率，单位：%。
close_yieldnumber收盘收益率，单位：%。
volumenumber成交量，沿用新浪源端口径。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "bond_gb_us_sina",
    limit=1,
    start_date='20220824',
    symbol='美国10年期国债',
)
