期货历史逐笔

futures_trades_history_tdx

请求指定交易日期货逐笔成交，返回秒级时间、成交价、成交量、仓差和可确认的开平类型。

请求指定交易日期货逐笔成交，返回秒级时间、成交价、成交量、仓差和可确认的开平类型。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
trade_datedate是交易日期，YYYYMMDD 或 YYYY-MM-DD。
limitinteger否每个品种返回多少笔，默认返回最新一页的 120 笔；all=true 时作为总数量上限。120
allboolean否是否自动翻页取完整逐笔，并按时间顺序返回；默认 false。false
page_sizeinteger否all=true 时每页请求笔数，默认 1800。1800
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 期货历史逐笔 client.call("futures_trades_history_tdx", code="IC2607.CFFEX", trade_date="20260703", limit=3)

返回字段

字段类型说明
instrument_idstringAxData 统一品种代码。
symbolstring源端品种代码。
exchangestring交易所或资产场所。
namestring可确认时返回品种名称。
trade_datedate交易日期。
time_labelstring成交时间，精确到秒。
pricenumber成交价。
volumeinteger成交量，按源端逐笔口径返回。
position_changeinteger仓差；源端有值时返回。
open_close_typestring开平类型；可确认时返回，如双开、双平、多开、空开、多平、空平、多换、空换、换手。
