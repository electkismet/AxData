接口文档 / 财联社

板块轮动

cls_sector_rotation

临时获取财联社板块轮动数据，默认不入库。

接口信息

接口名
cls_sector_rotation
Provider
axdata.source.cls
数据源
财联社 / cls
目录
财联社 / 板块数据
资产类型
stock
请求模式
source_request
采集支持
否

请求近 N 日每日涨幅靠前板块，默认不入库。

参数

参数类型必填说明默认值
daysinteger否查询天数，默认 4。4

返回字段

字段类型说明
trade_datedate交易日期。
plate_codestring板块代码。
plate_namestring板块名称。
change_pctnumber涨跌幅。
rankinteger当日排名。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "cls_sector_rotation",
    days=4,
)

POST /v1/request/cls_sector_rotation

  }
}
