接口文档 / 腾讯财经

A股逐笔成交

stock_zh_a_tick_tx_js

临时获取腾讯财经A股逐笔成交数据，默认不入库。

接口信息

接口名
stock_zh_a_tick_tx_js
Provider
axdata.source.tencent
数据源
腾讯财经 / tencent
目录
腾讯财经 / 逐笔数据
资产类型
stock
请求模式
source_request
采集支持
否

临时请求单只股票逐笔成交单页小样本，默认不入库。

参数

参数类型必填说明默认值
codestring是证券代码，支持 000001.SZ、sz000001、000001。
pageinteger否源端页码，默认 0。0
limitinteger否最多返回行数，默认 100，最大 500。100

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
sequenceinteger源端逐笔序号。
trade_timestring成交时间，源端日内时间 HH:MM:SS。
pricenumber成交价格，单位：元。
changenumber价格变动，单位：元。
volumenumber成交量，沿用腾讯源端逐笔口径。
amountnumber成交金额，单位：元。
trade_sidestring成交性质：buy 买盘、sell 卖盘、neutral 中性盘。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_zh_a_tick_tx_js",
    code='000001.SZ',
    limit=1,
    page=0,
)

HTTP API

POST /v1/request/stock_zh_a_tick_tx_js
Content-Type: application/json

{
  "params": {
    "code": "000001.SZ",
    "page": 0,
    "limit": 1
  }
}
