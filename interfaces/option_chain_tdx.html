期权T型报价

option_chain_tdx

用期权合约列表和实时快照拼出 T 型报价，按行权价组织认购、认沽两侧行情。

接口信息

接口名
option_chain_tdx
Provider

数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 期权数据
资产类型
option
请求模式
source_request
采集支持
否

用期权合约列表和实时快照拼出 T 型报价，按行权价组织认购、认沽两侧行情。

参数

参数类型必填说明默认值
product_codestring否期权品种代码过滤，例如 AP；不传则按其它参数筛选。
contract_monthstring否合约月份过滤，YYYYMM。
exchangestring否交易所过滤；不传表示全部。
limitinteger否拼 T 型报价前最多请求多少个期权合约，默认 100。100
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 苹果期权T型报价 client.call("option_chain_tdx", product_code="AP", contract_month="202610", limit=3)
