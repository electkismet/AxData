ETFK线

etf_kline_tdx

获取 ETF K 线，包含 OHLC、成交量额。

接口信息

接口名
etf_kline_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / ETF数据 / 行情数据
资产类型
etf
请求模式
source_request
采集支持
否

ETF K 线和指数 K 线使用同一套报文结构，上涨家数和下跌家数对 ETF 通常为空。

参数

参数类型必填说明默认值
codestring是ETF 代码：支持 510050.SH、159915.SZ、sh510050；批量可传列表或英文逗号分隔。
periodstring否K线周期：day、week、month、quarter、year、1m、5m、15m、30m、60m；默认 day。"day"
countinteger否返回条数，默认 120，适合源端直取预览；需要更长历史时显式传 count。120
参数示例

# 日K client.call("etf_kline_tdx", code="510050.SH", period="day", count=800) # 5分钟K client.call("etf_kline_tdx", code="510050.SH", period="5m", count=300)

返回字段

字段类型说明
instrument_idstringAxData 统一指数代码，例如 000001.SH。
symbolstring交易所原始六位指数代码。
tdx_codestringTDX 带市场前缀代码，例如 sh000001。
exchangestringAxData 交易所代码：SSE、SZSE 或 BSE。
trade_timedatetimeK 线时间。
periodstringK 线周期。
opennumber开盘点位。
highnumber最高点位。
lownumber最低点位。
closenumber收盘点位。
volumenumber指数 K 线成交量。
amountnumber指数 K 线成交额，单位：元。
up_countinteger上涨家数。
down_countinteger下跌家数。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "etf_kline_tdx",
    code='510050.SH',
    count=3,
    period='day',
)

HTTP API

POST /v1/request/etf_kline_tdx
Content-Type: application/json

{
  "params": {
    "code": "510050.SH",
    "period": "day",
    "count": 3
  }
}
