接口文档 / 巨潮

历史分红

stock_dividend_cninfo

临时获取巨潮历史分红数据，默认不入库。

接口信息

接口名
stock_dividend_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 分红融资
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮历史分红 webapi，返回单只股票分红实施方案，默认不入库。

参数

参数类型必填说明默认值
codestring是股票代码，支持 600009、600009.SH。

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
announcement_datedate实施方案公告日期，格式 YYYYMMDD。
dividend_typestring分红类型。
bonus_share_rationumber送股比例，源端数值口径。
transfer_share_rationumber转增比例，源端数值口径。
cash_dividend_rationumber派息比例，源端数值口径。
record_datedate股权登记日，格式 YYYYMMDD。
ex_right_datedate除权日，格式 YYYYMMDD。
dividend_payment_datedate派息日，格式 YYYYMMDD。
share_arrival_datedate股份到账日，格式 YYYYMMDD。
plan_descriptionstring实施方案分红说明。
report_periodstring报告时间/报告期，沿用巨潮源端文本。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_dividend_cninfo",
    code='600009.SH',
)

POST /v1/request/stock_dividend_cninfo
Content-Type: application/json

{
  "params": {
    "code": "600009.SH"
  }
}
