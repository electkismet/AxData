AxData

AxData 将数据源接口、采集任务、开放文件存储、本地查询、插件管理、Python SDK、HTTP API 和 Web 控制台放在同一个可扩展的数据平台里，面向个人量化研究、本地数据管理和数据源插件开发。

项目边界

数据源接口

Provider 插件负责一次性源端请求，返回 AxData 字段，默认不写入 data 目录。

采集器

Collector 插件负责显式采集任务、Parquet 写出、质量检查和元数据记录。
