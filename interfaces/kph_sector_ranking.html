接口文档 / 开盘红

板块排行

kph_sector_ranking

临时获取开盘红板块排行数据，默认不入库。

接口信息

接口名
kph_sector_ranking
Provider
axdata.source.kph
数据源
开盘红 / kph
目录
开盘红 / 板块数据
资产类型
stock
请求模式
source_request
采集支持
否

请求开盘红精选/行业/地区板块排行，默认不入库。

参数

参数类型必填说明默认值
trade_datestring是交易日期，YYYYMMDD 或 YYYY-MM-DD。
sector_typestring否板块类型：selected、industry、region，默认 selected。"selected"
fetch_allboolean否是否分页获取全部，默认 false。false

返回字段

字段类型说明
trade_datedate交易日期。
plate_idstring板块 ID。
plate_namestring板块名称。
sector_typestring板块类型。
change_pctnumber涨跌幅。
amountnumber成交额，单位：元。
amplitudenumber振幅。
net_inflownumber净流入，单位：元。
turnover_ratenumber换手率。
market_capnumber总市值，单位：元。
stock_countinteger成分股数量。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "kph_sector_ranking",
    sector_type='selected',
    trade_date='20260513',
)
