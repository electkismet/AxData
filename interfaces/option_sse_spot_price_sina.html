上交所期权实时行情

option_sse_spot_price_sina

临时获取新浪财经上交所期权实时行情数据，默认不入库。

接口信息

接口名
option_sse_spot_price_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期权行情
资产类型
option
请求模式
source_request
采集支持
否

临时请求新浪上交所期权实时行情，默认不入库。

参数

参数类型必填说明默认值
symbolstring否期权合约代码，支持 10011799 或 CON_OP_10011799；默认 10011799。"10011799"

返回字段

字段类型说明
option_codestring上交所期权合约数字代码。
sina_symbolstring新浪期权行情代码，例如 CON_OP_10011799。
buy_volumenumber买量，源端口径。
buy_pricenumber买价，单位/口径沿用新浪源端。
latest_pricenumber最新价，单位/口径沿用新浪源端。
sell_pricenumber卖价，单位/口径沿用新浪源端。
sell_volumenumber卖量，源端口径。
open_interestnumber持仓量，源端口径。
change_pctnumber涨幅，源端百分比数值口径。
exercise_pricenumber行权价，单位/口径沿用新浪源端。
prev_closenumber昨收价，单位/口径沿用新浪源端。
opennumber开盘价，单位/口径沿用新浪源端。
limit_upnumber涨停价，单位/口径沿用新浪源端。
limit_downnumber跌停价，单位/口径沿用新浪源端。
quote_timestring行情时间，源端字符串。
quote_statusstring源端行情状态。
status_codestring源端状态码。
underlying_typestring标的证券类型，源端编码。
underlyingstring期权标的证券代码。
contract_namestring期权合约简称。
amplitudenumber振幅，源端百分比数值口径。
highnumber最高价，单位/口径沿用新浪源端。
lownumber最低价，单位/口径沿用新浪源端。
volumenumber成交量，单位/口径沿用新浪源端。
amountnumber成交额，金额单位/口径沿用新浪源端。
