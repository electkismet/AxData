接口文档 / 东方财富

大盘指数实时行情

eastmoney_market_index_realtime

临时获取东方财富大盘指数实时行情数据，默认不入库。

接口信息

接口名
eastmoney_market_index_realtime
Provider
axdata.source.eastmoney
数据源
东方财富 / eastmoney
目录
东方财富 / 指数数据
资产类型
index
请求模式
source_request
采集支持
否

请求东方财富指数实时行情，默认只返回常用指数，默认不入库。

参数

参数类型必填说明默认值
scopestring否指数范围：default 常用指数，all 全部指数。"default"
limitinteger否最多返回条数，默认 100。100

返回字段

字段类型说明
index_codestring指数代码。
index_namestring指数名称。
last_pricenumber最新价。
change_pctnumber涨跌幅，百分比数值。
changenumber涨跌额。
volumenumber成交量，源端口径。
amountnumber成交额，单位：元。
highnumber最高价。
lownumber最低价。
opennumber开盘价。
pre_closenumber昨收价。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "eastmoney_market_index_realtime",
    limit=6,
    scope='default',
)
