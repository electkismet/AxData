龙虎榜每日详情

stock_lhb_detail_daily_sina

临时获取新浪财经龙虎榜每日详情数据，默认不入库。

接口信息

接口名
stock_lhb_detail_daily_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 龙虎榜
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪龙虎榜每日详情页面并解析汇总表，默认不入库。

参数

参数类型必填说明默认值
datestring否交易日期，YYYYMMDD 或 YYYY-MM-DD；默认 20240222。"20240222"
limitinteger否最多返回行数，默认 200，最大 5000。200

返回字段

字段类型说明
trade_datedate交易日期，格式 YYYYMMDD。
rankinteger源端表内序号。
instrument_idstringAxData 统一证券代码。
symbolstring六位股票代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring股票名称。
closenumber收盘价，单位：元。
metric_valuenumber对应值，源端百分比或指标数值口径。
volume_10k_sharesnumber成交量，单位：万股。
amount_10k_yuannumber成交额，单位：万元。
indicatorstring龙虎榜上榜指标/原因。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_lhb_detail_daily_sina",
    date='20240222',
    limit=1,
)

POST /v1/request/stock_lhb_detail_daily_sina
