接口文档 / 新浪财经

新浪开放式基金规模

fund_scale_open_sina

临时获取新浪财经新浪开放式基金规模数据，默认不入库。

接口信息

接口名
fund_scale_open_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 基金规模
资产类型
fund
请求模式
source_request
采集支持
否

临时请求新浪基金规模开放式基金单页 JSONP，默认不入库。

参数

参数类型必填说明默认值
symbolstring否基金类型：股票型基金、混合型基金、债券型基金、货币型基金、QDII基金；也兼容源端 type2 代码；默认 股票型基金。"股票型基金"
pageinteger否页码，默认 1。1
limitinteger否当前页最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
rankinteger源端排序序号，从 1 开始。
fund_codestring六位基金代码。
fund_namestring基金简称。
fund_categorystring基金规模分类，例如 封闭式基金。
unit_navnumber单位净值，单位：元。
total_raised_scalenumber总募集规模，单位/口径沿用新浪源端。
latest_total_sharenumber最近总份额，单位/口径沿用新浪源端。
established_datedate成立日期，格式 YYYYMMDD。
fund_managerstring基金经理。
nav_datedate净值更新日期，格式 YYYYMMDD。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "fund_scale_open_sina",
    limit=1,
    page=1,
    symbol='股票型基金',
)
