基金净值

fund_nav_tdx

返回可确认的基金净值、累计净值和净值日期；ETF交易类接口仍在ETF数据里。

接口信息

接口名
fund_nav_tdx
Provider
axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 基金数据
资产类型
fund
请求模式
source_request
采集支持
否

返回可确认的基金净值、累计净值和净值日期；ETF交易类接口仍在ETF数据里。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 基金净值 client.call("fund_nav_tdx", code="159007")

返回字段

字段类型说明
fund_idstringAxData 基金代码。
symbolstring基金代码。
fund_typestring基金类型。
namestring可确认时返回基金名称。
update_datedate净值日期。
navnumber单位净值。
accumulated_navnumber累计净值或累计值。
