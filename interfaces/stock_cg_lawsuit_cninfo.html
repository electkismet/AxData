接口文档 / 巨潮

公司诉讼

stock_cg_lawsuit_cninfo

临时获取巨潮公司诉讼数据，默认不入库。

接口信息

接口名
stock_cg_lawsuit_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 公司治理
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮公司诉讼专题统计，按公告区间和市场返回，默认不入库。

参数

参数类型必填说明默认值
marketstring否市场板块：全部、沪市、深市主板、创业板、科创板；默认 沪市。"沪市"
start_datestring否公告统计开始日期，YYYYMMDD 或 YYYY-MM-DD；默认 20180630。"20180630"
end_datestring否公告统计结束日期，YYYYMMDD 或 YYYY-MM-DD；默认 20210927。"20210927"
limitinteger否最多返回行数，默认 100，最大 1000。100

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
announcement_periodstring公告统计区间，沿用巨潮源端文本。
lawsuit_countnumber诉讼次数，单位：次。
lawsuit_amountnumber诉讼金额，金额单位/口径沿用巨潮源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_cg_lawsuit_cninfo",
    end_date='20210927',
    limit=1,
    market='沪市',
    start_date='20180630',
)
