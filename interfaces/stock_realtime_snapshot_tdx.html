实时快照

stock_realtime_snapshot_tdx

获取当前行情快照，返回价格、成交量额、内外盘、买一卖一、已解析盘中指标和派生指标。

接口信息

接口名
stock_realtime_snapshot_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / 实时数据
资产类型
stock
请求模式
source_request
采集支持
否

这个接口按股票代码请求当前行情快照，每个标的一般返回 1 行，适合做实时列表和个股详情页的行情总览。涨速、短换手、2分钟金额、开盘抢筹、量涨速、委比来自实时快照解析；开盘涨幅、最高涨幅、最低涨幅、均价、均涨幅、回头波、攻击波、内外比、开盘占比、封单额、买卖一量差由当前快照字段计算。

参数

参数类型必填说明默认值
codestring是证券代码：支持 000001、000001.SZ、sz000001；批量可传列表或英文逗号分隔字符串。
参数示例

# 单个标的 client.call("stock_realtime_snapshot_tdx", code="000001.SZ") # 批量请求多个标的 client.call("stock_realtime_snapshot_tdx", code=["000001.SZ", "600000.SH"])

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码，例如 000001.SZ。
symbolstring交易所原始六位代码。
tdx_codestringTDX 带市场前缀代码，例如 sz000001。
exchangestringAxData 交易所代码：SSE、SZSE 或 BSE。
last_pricenumber最新价，单位：元。
pre_closenumber昨收价，单位：元。
opennumber开盘价，单位：元。
highnumber最高价，单位：元。
lownumber最低价，单位：元。
changenumber涨跌额，单位：元。
change_pctnumber百分比数值；例如 1.23 表示上涨 1.23%，-0.85 表示下跌 0.85%。
open_change_pctnumber开盘涨幅，派生计算：(开盘价 - 昨收价) / 昨收价 * 100。
high_change_pctnumber最高涨幅，派生计算：(最高价 - 昨收价) / 昨收价 * 100。
low_change_pctnumber最低涨幅，派生计算：(最低价 - 昨收价) / 昨收价 * 100。
amplitude_pctnumber百分比数值；按 (最高价 - 最低价) / 昨收价 * 100 计算。
average_pricenumber均价，派生计算：成交额 / (成交量 * 100)，单位：元。
average_change_pctnumber均涨幅，派生计算：(均价 - 昨收价) / 昨收价 * 100。
drawdown_pctnumber回头波，派生计算：(最高价 - 最新价) / 昨收价 * 100。
attack_pctnumber攻击波，派生计算：(最新价 - 最低价) / 昨收价 * 100。
volumeinteger总成交量，单位：手。
current_volumeinteger最近一笔成交量，单位：手；不是累计成交量。
amountnumber成交额，单位：元。
inside_volumeinteger内盘成交量，单位：手。
outside_volumeinteger外盘成交量，单位：手。
inside_outside_rationumber内外比，派生计算：内盘 / 外盘。
open_amountnumber开盘金额，单位：元。
open_amount_ratio_pctnumber开盘占比，派生计算：开盘金额 / 成交额 * 100。
bid1_pricenumber买一价，单位：元。
bid1_volumeinteger买一量，单位：手。
ask1_pricenumber卖一价，单位：元。
ask1_volumeinteger卖一量，单位：手。
locked_amountnumber封单额，按买一价 * 买一量 * 100 计算，单位：元。
bid1_ask1_volume_diffinteger买一量减卖一量，单位：手。
bid1_ask1_balance_pctnumber买一卖一量差占比，按 (买一量 - 卖一量) / (买一量 + 卖一量) * 100 计算。
rise_speednumber涨速，百分比数值。
short_turnovernumber短换手，百分比数值。
min2_amountnumber近 2 分钟成交金额，单位：元。
opening_rushnumber开盘抢筹，百分比数值。
vol_rise_speednumber量涨速，百分比数值。
entrust_rationumber委比，百分比数值。
activityinteger活跃度，通达信实时快照携带的活跃度数值。
