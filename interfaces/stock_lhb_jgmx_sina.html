龙虎榜机构席位明细

stock_lhb_jgmx_sina

临时获取新浪财经龙虎榜机构席位明细数据，默认不入库。

接口信息

接口名
stock_lhb_jgmx_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 龙虎榜
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪龙虎榜机构席位明细单页，默认不入库。

参数

参数类型必填说明默认值
pageinteger否页码，默认 1。1
limitinteger否当前页最多返回行数，默认 40，最大 1000。40

返回字段

字段类型说明
pageinteger源端页码。
rankinteger当前页内序号，从 1 开始。
instrument_idstringAxData 统一证券代码。
symbolstring六位股票代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring股票名称。
trade_datedate交易日期，格式 YYYYMMDD。
institution_buy_amount_10k_yuannumber机构席位买入额，单位：万元。
institution_sell_amount_10k_yuannumber机构席位卖出额，单位：万元。
trade_typestring上榜类型，源端中文口径；为空时返回 null。

Python SDK

import axdata as ax
