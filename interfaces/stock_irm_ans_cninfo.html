接口文档 / 巨潮

互动易回答详情

stock_irm_ans_cninfo

临时获取巨潮互动易回答详情数据，默认不入库。

接口信息

接口名
stock_irm_ans_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 互动易
资产类型
stock
请求模式
source_request
采集支持
否

临时请求互动易单条问答详情，默认不入库。

参数

参数类型必填说明默认值
question_idstring是互动易问题编号，可从 stock_irm_cninfo 的 question_id 获取。

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring公司简称。
question_idstring互动易问题编号。
questionstring提问内容。
answerstring回答内容。
questionerstring提问者。
question_timedatetime提问时间，Asia/Shanghai，格式 YYYYMMDDHHMMSS。
answer_timedatetime回答时间，Asia/Shanghai，格式 YYYYMMDDHHMMSS。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_irm_ans_cninfo",
    question_id='1495108801386602496',
)

HTTP API

POST /v1/request/stock_irm_ans_cninfo
Content-Type: application/json

{
  "params": {
    "question_id": "1495108801386602496"
  }
}
