新浪可转债详情资料

bond_cb_profile_sina

临时获取新浪财经新浪可转债详情资料数据，默认不入库。

接口信息

接口名
bond_cb_profile_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 可转债
资产类型
bond
请求模式
source_request
采集支持
否

临时请求新浪可转债详情资料页并解析资料项长表，默认不入库。

参数

参数类型必填说明默认值
symbolstring否可转债代码、AxData 债券代码或新浪代码，例如 sz128039；默认 sz128039。"sz128039"
limitinteger否最多返回资料项行数，默认 100，最大 1000。100

返回字段

字段类型说明
instrument_idstringAxData 统一债券代码。
symbolstring六位债券代码。
sina_symbolstring新浪带市场前缀代码，例如 sz128039。
exchangestring交易所代码：SSE、SZSE。
sequenceinteger源端资料项顺序，从 1 开始。
item_namestring资料项名称。
item_valuestring资料项取值，保留新浪源端文本口径。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "bond_cb_profile_sina",
    limit=1,
    symbol='sz128039',
)

POST /v1/request/bond_cb_profile_sina
Content-Type: application/json

{

    "limit": 1
  }
