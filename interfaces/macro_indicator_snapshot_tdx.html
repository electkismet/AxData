宏观指标快照

macro_indicator_snapshot_tdx

请求宏观指标最近值；单位未确认时保持为空。

接口信息

接口名
macro_indicator_snapshot_tdx
Provider
axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 宏观数据
资产类型
macro
请求模式
source_request
采集支持
否

请求宏观指标最近值；单位未确认时保持为空。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 宏观指标快照 client.call("macro_indicator_snapshot_tdx", code="1_GDP.MACRO")

返回字段

字段类型说明
indicator_idstringAxData 宏观指标代码。
symbolstring源端指标代码。
namestring可确认时返回指标名称。
indicator_categorystring指标分类；可确认时返回。
valuenumber最新值。
period_datedate指标期日期。
pre_valuenumber上一期值。
unitstring单位；未确认时为空。
frequencystring发布频度；未确认时为空。

import axdata as ax
