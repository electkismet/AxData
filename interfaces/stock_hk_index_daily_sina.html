新浪港股指数日行情

stock_hk_index_daily_sina

临时获取新浪财经新浪港股指数日行情数据，默认不入库。

接口信息

接口名
stock_hk_index_daily_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 指数数据
资产类型
index
请求模式
source_request
采集支持
否

临时请求新浪港股指数 KLC 日行情并用纯 Python 解码，默认不入库。

参数

参数类型必填说明默认值
symbolstring否港股指数代码，支持 CES100、HSI 或 hkCES100 形式；默认 CES100。"CES100"
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
limitinteger否最多返回最近 N 行，默认 100，最大 10000。100

返回字段

字段类型说明
index_codestring港股指数代码，例如 CES100、HSI。
sina_symbolstring新浪港股指数行情代码，例如 hkCES100。
marketstring市场代码，固定为 HK。
asset_typestring资产类型，固定为 index。
trade_datedate交易日期，格式 YYYYMMDD。
opennumber开盘点位。
highnumber最高点位。
lownumber最低点位。
closenumber收盘点位。
volumenumber成交量，单位/口径沿用新浪源端。
amountnumber成交额，金额单位/口径沿用新浪源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_hk_index_daily_sina",
    limit=1,
    symbol='CES100',
)

HTTP API

POST /v1/request/stock_hk_index_daily_sina
Content-Type: application/json

{
  "params": {
    "symbol": "CES100",
    "limit": 1
  }
}
