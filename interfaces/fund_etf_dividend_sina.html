接口文档 / 新浪财经

ETF 累计分红

fund_etf_dividend_sina

临时获取新浪财经ETF 累计分红数据，默认不入库。

接口信息

接口名
fund_etf_dividend_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 基金行情
资产类型
fund
请求模式
source_request
采集支持
否

临时请求新浪 ETF hfq.js 分红数组，默认不入库。

参数

参数类型必填说明默认值
symbolstring否基金代码，支持 sh510050、sz159998、510050.SH；默认 sh510050。"sh510050"
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
limitinteger否最多返回行数，默认 100，最大 5000。100

返回字段

字段类型说明
instrument_idstringAxData 统一基金代码。
fund_codestring六位基金代码。
sina_symbolstring新浪带市场前缀代码，例如 sh510050。
exchangestring交易所代码：SSE、SZSE、BSE。
dividend_datedate分红日期，格式 YYYYMMDD。
accumulated_dividendnumber累计分红，单位/口径沿用新浪源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "fund_etf_dividend_sina",
    limit=1,
    symbol='sh510050',
)

HTTP API

POST /v1/request/fund_etf_dividend_sina
Content-Type: application/json

{
  "params": {
    "symbol": "sh510050",
    "limit": 1
  }
}
