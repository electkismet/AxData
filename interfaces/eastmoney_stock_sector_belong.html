个股所属板块

eastmoney_stock_sector_belong

临时获取东方财富个股所属板块数据，默认不入库。

接口信息

接口名
eastmoney_stock_sector_belong
Provider
axdata.source.eastmoney
数据源
东方财富 / eastmoney
目录
东方财富 / 板块数据
资产类型
stock
请求模式
source_request
采集支持
否

批量查询股票所属行业板块，默认不入库。

参数

参数类型必填说明默认值
codestring是股票代码，支持逗号分隔多只。

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
sector_namestring所属行业板块。

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "eastmoney_stock_sector_belong",
    code='000001.SZ',
