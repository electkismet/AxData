接口文档 / 新浪财经

上交所期权到期日

option_sse_expire_day_sina

临时获取新浪财经上交所期权到期日数据，默认不入库。

接口信息

接口名
option_sse_expire_day_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期权行情
资产类型
option
请求模式
source_request
采集支持
否

临时请求新浪上交所期权到期日与剩余天数，默认不入库。

参数

参数类型必填说明默认值
symbolstring否期权标的代码或分类：510050/50ETF、510300/300ETF、510500/500ETF、588000/科创50、588080/科创板50；默认 50ETF。"50ETF"
trade_datestring否合约到期月份，YYYYMM 或 YYYY-MM；不传时取源端最近到期月份。

返回字段

字段类型说明
underlyingstring期权标的证券代码，例如 510050。
underlying_namestring期权标的源端分类名称，例如 50ETF。
expire_monthstring合约到期月份，格式 YYYYMM。
expire_datedate合约到期日，格式 YYYYMMDD。
remainder_daysinteger距离到期日的剩余自然日数，源端口径。
cate_idstring新浪源端期权分类 ID。
source_categorystring实际请求的新浪分类；过期月份可能使用 XD 前缀。
underlying_source_namestring源端标的证券名称。
underlying_sina_symbolstring源端标的行情代码，例如 s_sh510050。
exchangestring交易所代码；上交所期权为 SSE。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "option_sse_expire_day_sina",
    symbol='50ETF',
    trade_date='202607',
)
