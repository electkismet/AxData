扩展市场列表

tdx_ext_markets_tdx

读取本机扩展资产市场目录，用于查看期货、期权、基金、债券、外汇、宏观等市场分组。

接口信息

接口名

Provider
axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录

资产类型
stock
请求模式
source_request
采集支持
否

读取本机扩展资产市场目录，用于查看期货、期权、基金、债券、外汇、宏观等市场分组。

参数

参数类型必填说明默认值
asset_typestring否资产类型过滤：futures、option、fund、bond、fx、macro。
namestring否市场名称关键词过滤。
limitinteger否返回前多少行，默认 500。500
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 查看期货市场 client.call("tdx_ext_markets_tdx", asset_type="futures", limit=5)

返回字段

字段类型说明
market_namestring市场名称。
short_namestring市场简称。
market_groupstring市场分组。
asset_typestring资产类型。
asset_type_zhstring资产类型中文名。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "tdx_ext_markets_tdx",
    asset_type='futures',
