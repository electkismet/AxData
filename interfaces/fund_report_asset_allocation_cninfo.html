基金资产配置

fund_report_asset_allocation_cninfo

临时获取巨潮基金资产配置数据，默认不入库。

接口信息

接口名
fund_report_asset_allocation_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 基金报表
资产类型
fund
请求模式
source_request
采集支持
否

临时请求巨潮基金资产配置专题统计，默认不入库。

参数

无参数。

返回字段

字段类型说明
report_datedate报告期，格式 YYYYMMDD。
fund_countnumber基金覆盖家数，单位：只。
equity_asset_pctnumber股票权益类占净资产比例，源端百分比数值口径。
bond_asset_pctnumber债券固定收益类占净资产比例，源端百分比数值口径。
cash_asset_pctnumber现金货币类占净资产比例，源端百分比数值口径。
fund_market_net_assetsnumber基金市场净资产规模，金额单位/口径沿用巨潮源端。

Python SDK

import axdata as ax
