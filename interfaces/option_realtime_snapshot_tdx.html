期权实时快照

option_realtime_snapshot_tdx

请求期权当前快照，返回价格、结算、成交量额、持仓量和五档盘口。

接口信息

接口名
option_realtime_snapshot_tdx
Provider
axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 期权数据
资产类型
option
请求模式
source_request
采集支持
否

请求期权当前快照，返回价格、结算、成交量额、持仓量和五档盘口。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。
