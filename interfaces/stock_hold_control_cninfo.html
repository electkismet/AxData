接口文档 / 巨潮

实际控制人持股变动

stock_hold_control_cninfo

临时获取巨潮实际控制人持股变动数据，默认不入库。

接口信息

接口名
stock_hold_control_cninfo
Provider
axdata.source.cninfo
数据源
巨潮 / cninfo
目录
巨潮 / 股本股东
资产类型
stock
请求模式
source_request
采集支持
否

临时请求巨潮实际控制人持股变动专题统计，默认不入库。

参数

参数类型必填说明默认值
control_typestring否控制类型：单独控制、实际控制人、一致行动人、家族控制、全部；默认 实际控制人。"实际控制人"

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位证券代码。
exchangestring交易所代码：SSE、SZSE、BSE。
namestring证券简称。
change_datedate变动日期，格式 YYYYMMDD。
actual_controller_namestring实际控制人名称。
holding_sharesnumber控股数量，单位/口径沿用巨潮源端。
holding_rationumber控股比例，源端数值口径。
direct_controller_namestring直接控制人名称。
control_typestring控制类型。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_hold_control_cninfo",
    control_type='实际控制人',
)

HTTP API

POST /v1/request/stock_hold_control_cninfo
Content-Type: application/json

{
  "params": {
    "control_type": "实际控制人"
  }
}
