期货K线

futures_kline_tdx

请求期货K线，返回OHLC、成交量、持仓量和结算价。

接口信息

接口名
futures_kline_tdx
Provider

目录

source_request
采集支持
否

请求期货K线，返回OHLC、成交量、持仓量和结算价。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
periodstring否K线周期：1m、5m、15m、30m、60m、day、week、month、quarter、year；默认 day。"day"
limitinteger否每个品种返回前多少根，默认 30。30
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 期货日K client.call("futures_kline_tdx", code="IC2607.CFFEX", period="day", limit=3)

返回字段

字段类型说明
instrument_idstringAxData 统一品种代码。
symbolstring源端品种代码。
exchangestring交易所或资产场所。
namestring可确认时返回品种名称。
trade_timedateK线日期或时间。
periodstringK线周期。
opennumber开盘价或本期值。
highnumber最高价或本期高值。
lownumber最低价或本期低值。
closenumber收盘价或本期值。
volumeintegerK线成交量，按源端周期口径返回。
open_interestinteger持仓量；源端有值时返回。
settlementnumber结算价；源端有值时返回。
