控盘榜单

concept_control_ranking_tdx

查询行业或题材按日期返回的控盘榜单；每个日期内通常是前十名。

接口信息

接口名
concept_control_ranking_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / F10数据
资产类型
stock
请求模式
source_request
采集支持
否

查询行业或题材按日期返回的控盘榜单；每个日期内通常是前十名。

参数

参数类型必填说明默认值
concept_codestring是题材或行业 ID；可先从个股题材接口返回的 topic_id 中选择，部分 ID 可能没有控盘榜单。
countinteger否返回前多少条榜单记录，默认 20，最大 500；记录按日期榜单拍平后计数。20
参数说明

按题材或行业 ID 返回按日期拍平后的控盘榜单；不是相关板块 board_code，部分 ID 可能没有控盘榜单。

参数示例

client.call("concept_control_ranking_tdx", concept_code="2817", count=5)

返回字段

字段类型说明
datedate日期。
instrument_idstringAxData 统一证券代码，例如 000001.SZ。
exchangestringAxData 交易所代码：SSE、SZSE 或 BSE。
rankinteger排名。
market_codeinteger市场代码。
symbolstring股票代码。
namestring股票名称。
control_ratio_pctnumber控盘比例，单位：%。

Python SDK

import axdata as ax

client = ax.AxDataClient()
