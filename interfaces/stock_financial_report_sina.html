新浪 JSON 财务报表

stock_financial_report_sina

临时获取新浪财经新浪 JSON 财务报表数据，默认不入库。

接口信息

接口名
stock_financial_report_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 财务报表
资产类型
stock
请求模式
source_request
采集支持
否

临时请求新浪 JSON 财报接口并归一为长表，默认不入库。

参数

参数类型必填说明默认值
stockstring否股票代码，支持 sh600600、600600.SH、600600；默认 sh600600。"sh600600"
symbolstring否报表类型：资产负债表、利润表、现金流量表；也兼容 balance、income、cashflow；默认 资产负债表。"资产负债表"
limitinteger否最多报告期数量，默认 1，最大 100。1
item_limitinteger否每个报告期最多项目数，默认 200，最大 2000。200

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码。
symbolstring六位股票代码。
sina_symbolstring新浪带市场前缀代码，例如 sh600600。
exchangestring交易所代码：SSE、SZSE、BSE。
statement_typestring报表类型：balance、income、cashflow。
statement_namestring报表中文名称。
report_datedate报告期日期，格式 YYYYMMDD。
date_descriptionstring报告期说明，例如 2026一季报。
date_typeinteger源端报告期类型编码。
item_fieldstring源端项目字段编码。
item_namestring报表项目名称。
item_valuenumber项目数值，金额单位/口径沿用新浪源端。
item_display_typeinteger源端展示类型编码。
item_displaystring源端展示层级，例如 大类/小类。
item_precisionstring源端数值精度标记。
item_group_nointeger源端项目分组编号。
item_sourcestring源端项目所属报表源编码。
item_yoynumber项目同比，源端数值口径。
data_sourcestring报告数据来源。
is_auditstring是否审计，源端中文口径。
publish_datedate公告日期，格式 YYYYMMDD。
currencystring币种，例如 CNY。
report_typestring报告类型，例如 合并期末。
update_timeinteger源端更新时间 Unix 秒。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_financial_report_sina",
    item_limit=1,
    limit=1,
    stock='sh600600',
    symbol='资产负债表',
)
