期货实时快照

futures_realtime_snapshot_tdx

请求期货当前快照，返回最新价、结算价、成交量、成交额、持仓量和五档盘口等字段。

接口信息

接口名
futures_realtime_snapshot_tdx
Provider
axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 期货数据
资产类型
future
请求模式
source_request
采集支持
否

请求期货当前快照，返回最新价、结算价、成交量、成交额、持仓量和五档盘口等字段。

参数

参数类型必填说明默认值
codestring是品种代码；可传单个、列表或英文逗号分隔字符串。
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 期货快照 client.call("futures_realtime_snapshot_tdx", code="IC2607.CFFEX")
