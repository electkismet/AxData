新浪中国期货分钟线

futures_zh_minute_sina

临时获取新浪财经新浪中国期货分钟线数据，默认不入库。

接口信息

接口名
futures_zh_minute_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期货行情
资产类型
future
请求模式
source_request
采集支持
否

临时请求新浪期货单合约分钟线小样本，默认不入库。

参数

参数类型必填说明默认值
symbolstring否新浪期货合约代码，例如 RB0、IF2008；默认 RB0。"RB0"
periodstring否分钟周期，可选 1、5、15、30、60；默认 1。"1"
limitinteger否最多返回行数，默认 100，最大 2000。100

返回字段

字段类型说明
source_symbolstring新浪期货合约代码，例如 RB0 或 IF2008。
periodstring分钟周期，可选 1、5、15、30、60。
datetimedatetime分钟时间，格式 YYYYMMDDHHMMSS。
trade_datedate交易日期，格式 YYYYMMDD。
trade_timestring交易时间，格式 HH:MM:SS。
opennumber开盘价。
highnumber最高价。
lownumber最低价。
closenumber收盘价。
volumenumber成交量，单位：手。
open_interestnumber持仓量，单位：手。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "futures_zh_minute_sina",
    limit=1,
    period='1',
    symbol='RB0',
)

POST /v1/request/futures_zh_minute_sina
Content-Type: application/json

    "period": "1",

  }
}
