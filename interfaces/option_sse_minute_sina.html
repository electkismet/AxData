接口文档 / 新浪财经

上交所期权分钟行情

option_sse_minute_sina

临时获取新浪财经上交所期权分钟行情数据，默认不入库。

接口信息

接口名
option_sse_minute_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 期权行情
资产类型
option
请求模式
source_request
采集支持
否

临时请求新浪上交所期权当前交易日分钟行情，默认不入库。

参数

参数类型必填说明默认值
symbolstring否期权合约代码，支持 10011799 或 CON_OP_10011799；默认 10011799。"10011799"
limitinteger否按源端时间顺序最多返回行数，默认 241，最大 1000。241

返回字段

字段类型说明
option_codestring上交所期权合约数字代码。
sina_symbolstring新浪期权行情代码，例如 CON_OP_10011799。
trade_datedate交易日期，格式 YYYYMMDD；源端当前交易日口径。
trade_timestring分钟时间，格式 HH:MM:SS。
pricenumber分钟价格，单位/口径沿用新浪源端。
volumenumber分钟成交量，单位/口径沿用新浪源端。
open_interestnumber持仓量，源端口径。
avg_pricenumber均价，单位/口径沿用新浪源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "option_sse_minute_sina",
    limit=1,
    symbol='10011799',
)

POST /v1/request/option_sse_minute_sina
Content-Type: application/json

{

    "limit": 1
