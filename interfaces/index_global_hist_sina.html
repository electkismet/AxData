接口文档 / 新浪财经

全球指数历史行情

index_global_hist_sina

临时获取新浪财经全球指数历史行情数据，默认不入库。

接口信息

接口名
index_global_hist_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 指数行情
资产类型
index
请求模式
source_request
采集支持
否

临时请求新浪全球指数历史 JSON，默认不入库。

参数

参数类型必填说明默认值
symbolstring否指数名称或新浪代码，例如 瑞士股票指数、SWI20；默认 瑞士股票指数。"瑞士股票指数"
start_datestring否开始日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
end_datestring否结束日期，YYYYMMDD 或 YYYY-MM-DD；不传不过滤。
limitinteger否最多返回最近 N 行，默认 100，最大 10000。100

返回字段

字段类型说明
index_codestring新浪全球指数代码。
index_namestring指数中文名称；直接传代码时可能为空。
trade_datedate交易日期，格式 YYYYMMDD。
opennumber开盘点位。
highnumber最高点位。
lownumber最低点位。
closenumber收盘点位。
volumenumber成交量，单位/口径沿用新浪源端。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "index_global_hist_sina",
    limit=1,
    symbol='瑞士股票指数',
)

HTTP API

POST /v1/request/index_global_hist_sina
Content-Type: application/json

{
  "params": {
    "symbol": "瑞士股票指数",
    "limit": 1
  }
}
