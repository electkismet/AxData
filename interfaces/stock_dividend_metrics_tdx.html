分红指标

stock_dividend_metrics_tdx

查询股息率、股利支付率、派现融资等分红指标。

接口信息

接口名
stock_dividend_metrics_tdx
Provider
axdata.source.tdx_external
数据源
通达信 / tdx
目录
通达信 / 股票数据 / F10数据
资产类型
stock
请求模式
source_request
采集支持
否

查询股息率、股利支付率、派现融资等分红指标。

参数

参数类型必填说明默认值
codestring是股票代码：支持 000001、000001.SZ、sz000001；批量可传列表或英文逗号分隔字符串。
metricstring否指标：dividend_yield 股息率、payout_ratio 股利支付率、cash_financing 派现融资；默认 dividend_yield。"dividend_yield"
viewstring否展示方式：trend 走势、ranking 排名、summary 总览；不传时 dividend_yield/payout_ratio 默认 trend，cash_financing 默认 summary。
参数示例

# 单个标的 client.call("stock_dividend_metrics_tdx", code="000001.SZ") # 批量请求多个标的 client.call("stock_dividend_metrics_tdx", code=["000034.SZ", "000001.SZ"])

返回字段

字段类型说明
instrument_idstringAxData 统一证券代码，例如 000001.SZ。
symbolstring交易所原始六位代码。
datedate日期或期间。
metric_valuenumber指标值。
benchmark_valuenumber对照值。
rankinteger排名。
stock_namestring证券简称。
stock_codestring股票代码。
summary_totalnumber汇总总额。
cash_dividend_totalnumber累计现金分红。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(

    code='000001.SZ',
