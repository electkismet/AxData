新浪港股指数实时行情

stock_hk_index_spot_sina

临时获取新浪财经新浪港股指数实时行情数据，默认不入库。

接口信息

接口名
stock_hk_index_spot_sina
Provider
axdata.source.sina
数据源
新浪财经 / sina
目录
新浪财经 / 指数数据
资产类型
index
请求模式
source_request
采集支持
否

临时请求新浪港股指数实时行情小样本，默认不入库。

参数

参数类型必填说明默认值
symbolsstring否逗号分隔的新浪港股指数代码，例如 hkHSI,HSTECH；也可传 all 或 全部；默认 hkHSI,hkHSCEI,hkHSTECH。"hkHSI,hkHSCEI,hkHSTECH"
limitinteger否最多返回行数，默认等于请求代码数，最大 100。3

返回字段

字段类型说明
sina_symbolstring新浪港股指数行情代码，例如 hkHSI。
index_codestring港股指数代码，例如 HSI。
marketstring市场代码，固定为 HK。
asset_typestring资产类型，固定为 index。
namestring指数名称。
latest_pricenumber最新点位。
changenumber涨跌额，单位：点。
change_pctnumber涨跌幅，源端百分比数值口径。
prev_closenumber昨收点位。
opennumber今开点位。
highnumber最高点位。
lownumber最低点位。

调用示例

Python SDK

import axdata as ax

client = ax.AxDataClient()
rows = client.call(
    "stock_hk_index_spot_sina",
    limit=1,
    symbols='hkHSI',
)
