扩展品种列表

tdx_ext_instruments_tdx

读取本机扩展资产品种目录，可按资产类型、代码、交易所或关键词过滤。

接口信息

接口名
tdx_ext_instruments_tdx
Provider
axdata.source.tdx_ext_external
数据源
通达信扩展行情 / tdx_ext
目录
通达信扩展行情 / 基础数据
资产类型
stock
请求模式
source_request
采集支持
否

读取本机扩展资产品种目录，可按资产类型、代码、交易所或关键词过滤。

参数

参数类型必填说明默认值
asset_typestring否资产类型过滤：futures、option、fund、bond、fx、macro。
codestring否品种代码过滤；可传单个、列表或英文逗号分隔字符串。
exchangestring否交易所或资产场所过滤；不传或 all 表示全部。
namestring否名称、品种或市场关键词过滤。
limitinteger否返回前多少行，默认 1000。1000
tdx_rootstring否本机通达信目录（可选，高级）
参数说明

默认不用传 tdx_root；只有 API 服务器上的通达信安装目录不是常见位置，或想指定某个 hq_cache 目录时才需要传。

参数示例

# 查看外汇品种 client.call("tdx_ext_instruments_tdx", asset_type="fx", limit=3)

返回字段

字段类型说明
instrument_idstringAxData 扩展资产统一代码。
symbolstring源端品种代码。
asset_typestring资产类型：futures 期货、option 期权、fund 基金、bond 债券、fx 外汇、macro 宏观。
exchangestring归一后的交易所或资产场所。
market_namestring本机扩展资产目录中的市场名称。
market_groupstring本机扩展资产目录中的分组名称。
product_codestring品种代码。
product_namestring品种名称。
contract_monthstring合约月份，YYYYMM。
contract_typestring可确认时返回合约类型。
option_typestring期权方向，可确认时为 call 或 put。
strike_pricenumber期权行权价。
fund_typestring基金市场类型。
bond_typestring债券市场类型。
base_currencystring基础货币。
quote_currencystring报价货币。
indicator_categorystring宏观指标分类。
